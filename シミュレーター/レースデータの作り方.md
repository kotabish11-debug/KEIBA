# シミュレーター用レースデータの作り方

重賞(G1・G2・G3、障害重賞を含む)の出走馬が登録されたら、このルールでレースデータを作る。
シミュレーター(https://claude.ai/artifact/P8QScqCpR36cPEkxMtou9s)は、届いたレースを自動でレース一覧に追加する。

## 1. 保存先
- ファイル: `シミュレーター/races/<レースID>.json`(1レース1ファイル、UTF-8)
- レースID: 英小文字と数字のみ。`<レース名のローマ字><年>`。例: `kikkasho2026`(菊花賞)、`artemis2026`(アルテミスS)、`tokyohj2026`(東京ハイジャンプ)
- シミュレーターへの反映: 同じ内容を ArtifactData で `races/<レースID>` に書く(手順は「4. シミュレーターへの書き込み」)

## 2. いつ作り、いつ直すか

| 段階(stage) | タイミング | やること |
|---|---|---|
| 特別登録 | 前週の日曜夜 | 登録馬全頭でファイルを作る。騎手が未定なら `"jockey": "未定"` |
| 出走確定 | 木曜〜金曜 | 出走しない馬を外し、騎手・斤量を確定の値にする |
| 枠順確定 | 木曜〜金曜 | `umaban` を入れる |
| 当日 | 当日朝〜発走 | `odds`(実オッズ、`oddsKari: false`)・`weight`・`weightDiff`・`going`・`scratched` を更新 |
| 結果確定 | レース後 | `stage` を「結果確定」にし、`result` に1〜3着の馬名を入れる |

能力値(実績〜騎手)は、特別登録か出走確定のときに付け、そのあとは大きな変化(乗り替わり・取消・馬場悪化)があったときだけ直す。

## 3. JSONの形

```json
{
  "id": "kikkasho2026",
  "name": "菊花賞",
  "grade": "GI",
  "date": "2026-10-25",
  "place": "京都",
  "no": 11,
  "time": "15:40",
  "surface": "芝",
  "dist": 3000,
  "dir": "右",
  "courseNote": "外回り",
  "cond": "3歳牡・牝 馬齢57kg",
  "stage": "出走確定",
  "chaos": 8,
  "weather": "晴(予報・降水10%)",
  "going": null,
  "updatedAt": "2026-10-23T18:30:00+09:00",
  "source": "スポーツナビ競馬・JRA・tenki.jp",
  "memo": "出走馬確定。枠順は金曜に発表",
  "horses": [
    {
      "name": "ロブチェン", "jockey": "松山弘平", "style": "先行",
      "jisseki": 92, "kyori": 78, "course": 80, "choshi": 85, "kishu": 88,
      "heavy": 0, "odds": 2.8, "oddsKari": true, "umaban": null,
      "note": "皐月賞・ダービーの二冠。神戸新聞杯も勝利。3000mは初めて。"
    }
  ]
}
```

- `grade`: `GI` / `GII` / `GIII` / `J・GI` / `J・GII` / `J・GIII`
- `surface`: `芝` / `ダ` / `障`。`courseNote`: `内回り` / `外回り` / 空文字
- `going`: 芝(障害は芝)の馬場。0=良 1=稍重 2=重 3=不良。未発表は `null`
- `chaos`(波乱度・省略可): G1は8、G2・G3は8.5、ハンデ戦と2歳戦は9.5、障害は9
- `courseBias`・`drawBias` は省略してよい(シミュレーターがコースから決める)
- 出走取消は、馬を消さずに `"scratched": true` を付ける

## 4. 能力値の付け方(各0〜100)

まずメンバーの中での順位を意識する。同じレースの中で差がつくように付ける。

| 項目 | 重み | 基準 |
|---|---|---|
| 実績 `jisseki` | 35% | G1勝ち 90〜95 / G1で2〜3着・G2勝ち 85〜89 / G2・G3で2〜3着・G3勝ち 78〜84 / OP・L勝ち、重賞で掲示板 70〜77 / 3勝クラス勝ち 62〜69 / 2勝クラス以下 50〜61。2歳戦は、新馬・未勝利勝ち 65前後、1勝クラス・OP勝ち 72前後、重賞勝ち 82前後 |
| 距離 `kyori` | 15% | 同じ距離(±200m)で勝利・重賞好走 85〜90 / 経験があり好走 75〜84 / 未経験だが血統・走りから見込める 65〜74 / 大幅な延長・短縮で不安 45〜64 |
| コース `course` | 15% | 同じコースの重賞で好走 85〜 / 似たコース(小回り・直線の長さ・右左回り)で好走 75〜84 / 未知 65〜74 / 合わない 50〜64 |
| 調子 `choshi` | 20% | 前走勝ち・好時計・上昇中 85〜95 / 前走好走(5着以内) 70〜84 / 前走凡走 55〜69 / 大敗続き、または6か月以上の休み明け 40〜60 |
| 騎手 `kishu` | 15% | リーディング上位・G1常連(ルメール、川田、武豊、戸崎、坂井、松山、岩田望、横山武、短期免許の外国人トップ騎手など) 85〜95 / 重賞常連 75〜84 / 中堅 65〜74 / 若手・減量騎手 55〜64。障害は障害リーディングで同様に付ける |

- 脚質 `style`: 近3〜4走の4コーナー通過順で決める。ほぼ先頭=`逃げ`、頭数の前3割=`先行`、中団=`差し`、後方3割=`追込`
- 重馬場 `heavy`: 道悪で勝ち・好走 +2 / やや得意 +1 / 不明・普通 0 / やや苦手 -1 / 道悪で大敗 -2
- 仮オッズ `odds`(`oddsKari: true`): 実績と前評判から人気を想定して付ける。全頭の(1÷オッズ)の合計が1.25前後になるようにする。実オッズが出たら置き換えて `oddsKari: false`
- 根拠 `note`: 能力値の根拠を1〜2文(主な実績・前走・不安点)

## 5. シミュレーターへの書き込み
- ArtifactData を使えるときは、`url: https://claude.ai/artifact/P8QScqCpR36cPEkxMtou9s`、`collection: races`、`doc_id: <レースID>` に、JSONファイルの中身を書く
  - 新しいレース: `set`(`if_version` なし)
  - 既存のレース: 先に `get` して `version` を確認し、`set` に `if_version` を付ける
- 使えないときは、JSONファイルの保存だけでよい(PC側の同期のときに書き込まれる)
