# ワイドの買い方(4つの型)

出典: YouTube「上昇」のワイドの動画(ユーザー提供の文字起こし、2026-10-21)を要約。数値は動画内の説明で、自分で検証したものではない。

## 考え方
- ワイドは組み合わせが少なく(18頭で153通り。3連単は4896通り)当たりやすい。当たりが続くので資金が減りにくく、連敗して大勝負に走ることも防げる
- 平均配当は約6倍だが、型を選べば10〜20倍も狙える
- **同じ組の馬連を少額で添える**: ワイドが当たるとき、その2頭が1・2着のことが約3分の1ある
- 1回ごとではなく長期戦で考える

## 4つの型
| 型 | 組み合わせ | 使う場面 | 注意 |
|---|---|---|---|
| ① 人気×人気の1点 | 2〜3番人気 → 1〜4番人気 | 来そうな人気馬が2頭に絞れるとき | 人気同士のワイドの的中率は約20%なので、**5倍以上のときだけ**(期待値=的中率×オッズが1を超える)。単勝1倍台の1番人気がいるとき、それを外した人気同士のワイドは配当が高くなりやすい(例: 2025年皐月賞の3番人気×4番人気が12.8倍) |
| ② 人気×穴の流し | 軸=2〜3番人気から1頭 → 相手=5〜9番人気から2〜3頭 | 1番人気以外に信頼できる軸がいて、気になる穴馬が2〜3頭いるとき | 例: 2025年秋華賞 |
| ③ 穴×穴のボックス | 5番人気以下の4頭ボックス | 荒れそうなレース(道悪・ハンデ戦・若手騎手が多いローカルなど) | 点数を増やすと合成オッズが下がるので4頭まで。**同じ脚質でそろえる**(逃げ・先行どうし、差し・追込どうし)。荒れるときは展開がどちらかの脚質に偏ることが多い。例: 2025年スプリンターズSの逃げ・先行の穴4頭 |
| ④ 大穴×人気の流し | 10番人気以下の1頭 → 1〜3番人気(3点) | 「一発の条件」がそろった大穴がいて、相手が絞れないとき | 50〜70倍もある。例: 2025年菊花賞のエキサイトバイオ |

### 大穴の「一発の条件」
休み明け / 減量騎手(見習い) / 乗り替わり / 初めての芝・初めてのダート / 距離の短縮・延長 / 初めてのブリンカー / 本格化の兆し(近走で着順が上がってきた) / 馬体重の大きな増減

## シミュレーターへの反映(2026-10-21)
- シミュレーターは期待値(的中率×推定オッズ)で買い目を選ぶので、①の「5倍以上のときだけ」や、1倍台の人気馬を外した人気同士の配当が高いことは、計算の中で自然に扱われる
- ③の「同じ脚質の穴同士」も、シミュレーションで展開(ハイ・ミドル・スロー)を1回ごとに全馬へ同時にかけているので、同じ脚質の馬が一緒に来る確率は高めに出る
- 追加したこと: 買い目にワイドがあり、同じ2頭の馬連が期待値1以上なら、馬連を「おさえ」として少額で添える
- 一発の条件は自動では見ていない。重賞で手で能力値を付けるとき、該当する大穴は `note` に書き、`choshi` を下げすぎない

## 少ない予算(1レース1000円)での買い方(2026-10-21追加)
出典: YouTube「青木」(競馬副業のチャンネル)の少額の買い方の動画(ユーザー提供の文字起こし)を要約。

- 少額のよさ: 予算を守る習慣がつく / 外れても痛くないので、人気に流されず根拠のある自分の予想を試せる / 同じ資金で多くのレースに挑戦でき、振り返り(PDCA)の回数が増える。ただし上級者になったら、買うレースを絞って1レースに資金を集める方が効率が良い
- 少額では点数を広げず、1〜2点に集める
- 3つの作戦
  1. **中穴の単勝1点**(5〜10倍): 1番人気が3倍以上の混戦レースが基本。1倍台の人気馬に不安があるレースも狙い目(その分ほかの馬のオッズが付く)。選ぶときは減点ではなく**加点**(コース実績・前走の度外視できる負け・騎手強化・展開の後押しなど、勝ち切る武器があるか)
  2. **人気馬+穴馬のワイド1点**(3〜10倍): 信頼できる人気馬が1頭いて、1〜3番人気の中に不安な馬が混ざるレース。人気馬は減点法(崩れない馬)、穴馬(6〜10番人気)は加点法(何か1つ光る材料がある馬)で選ぶ
  3. **単勝+ワイドの分割**(応用): 単勝の馬は5倍以上、ワイドも5倍以上のときだけ。基本は500円ずつで、オッズの低い方に厚く置き、どちらが当たっても払戻が近くなるようにする。片方ずつでも損を抑えられ、両方当たれば大きい

**シミュレーターへの反映**
- 予算が少ないときは点数を絞る: 1000円までは2点、2000円までは3点(期待値と的中率から決めた配分で上位の買い目だけ残す)
- 単勝の4〜9.9倍中心・期待値で選ぶ仕組み・人気の偏ったレースで他の馬の期待値が上がることは、すでに計算に入っている
