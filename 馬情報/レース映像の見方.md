# レース映像(VTR)の見方

出典: YouTube「コタ」(ネット競馬のプロ予想家)「年間3000レース以上分析しているプロ予想家が教えるレースVTRの見方」(ユーザー提供の文字起こし、2026-10-22)。数値は動画内の説明で未検証。

馬柱(新聞・アプリ)には数字しか載らず、馬場・展開・騎乗が毎回違うので再現性が低い。映像を見る人は少ない(本人の感覚で競馬ファンの5%未満)ので、そこに差がつく。見るポイントは2つ。

## 1. 4コーナーで手応えがあった馬を見つける
- 4コーナーは各馬が一斉に仕掛けるところ。ここで騎手が追わずに持ったままの馬は余力(=能力か調子)がある。追っ付けている馬は余力がない
- 手応えが悪いのに追って追って好走した馬は「100の力を全部出した結果」で、次走に上積みが少ない。持ったままで回ってきた馬は上積みがある
- 本物の手応えの見分け方は2つ
  1. **推進力**: 抑えきれない勢いでグーンと進出している(一番大事)。脚を溜めているだけの馬(早く動くと止まるので我慢しているだけ)は見せかけ。特に内ラチ沿いをぴったり回ってくる馬に見せかけが多い
  2. **直線を向いてからも手応えがいい**: 直線に入ってすぐ全力で追い始める馬は違う。先行馬は直線でも楽な手応えで、満を持して追い出すくらいがよい(例: アーモンドアイのオークス)
- 直線で失速して7着などに負けても、直線途中まで手応えが良かった馬は何かのミスで着順を落とした可能性が高く、人気が落ちる次走で狙える
- コースで見る場所が変わる
  - 直線が短いコース(函館・札幌など): 3〜4コーナーからの手応えが良ければ合格
  - 直線が長いコース(東京など): 4コーナーの手応えは当たり前。直線前半まで持ったまま(東京なら残り400m付近まで)で合格
- 割り引いて見る3つ
  - **スローペース**: みんな楽に回ってくるので手応えは良く見える。評価するのは直線途中まで馬なりで伸びた馬だけ
  - **逃げ馬**: 前に馬がおらずペースも自分で作るので、手応えが良いのは普通。毎回楽に逃げている・直線半ばまで持ったまま、など際立つときだけ評価する
  - **ダート**: 直線が短く先行有利で、早めに動くのが当たり前。4コーナーで手応えが少し悪いのは減点しない。3コーナーから既に手応えが怪しい馬は次走も狙えない
- 手応えの良かった馬でも、次走が不向きな条件(苦手な道悪・出遅れて最後方・一団で詰まる展開など)なら来ない。敗因がはっきりしていれば、その次・その次で巻き返しを狙う

## 2. 馬場の有利不利を見極める
- 今の競馬は馬の能力差が小さく、重賞でも単勝100倍以上の馬が2・3着によく来る(本人の集計で2024年は9月までに8回、単勝万馬券の馬が激走)。その大きな理由の一つが有利な馬場を通ったこと
- 使い方は2つ
  1. 当日の馬場に合う馬をその日に買う(内有利なら内枠の逃げ・先行、外有利なら中・外枠の差し・追込)。ただし未勝利戦は能力差がそのまま位置取りに出るので(前にいる馬は単に強い)、前半のレースの傾向をメインに当てはめるのは難しい。下手に読むより、コースの基本(新潟千直は外有利、中山芝マイルは内有利など)を優先する
  2. **レース後に見直して、馬場の悪いところを走った馬を次走以降で狙う**(こちらを勧める。月曜・火曜でもできる)。馬場の不利で2着相当から5・6着に負けた馬は平気で巻き返す。例: 中山マイルで1番人気が16番枠に入って4着 → 次走2・3番人気で東京マイルなら突き抜ける
- **一番効くのは逆**: 馬場の良いところを走って好走した馬が次走で人気になったら危険。例: 千直の18番枠で2着 → 次走1番人気で新潟芝1200なら惨敗。「1番人気を消す技術は、穴を拾う技術よりはるかに大事」
- 新潟千直の7・8枠は勝率・複勝率が高いうえ、単複回収率も80%超(7枠の複勝はベタ買いで100%超)。外有利は誰でも知っているようで、実はまだ売れていない(本人の集計)
- 馬場の傾向(内か外か、前か後ろか)の判断
  1. 人気薄で激走した馬が、馬場のどこを通ったか・どんな脚質だったか(人気薄の激走は有利な馬場の後押しが多い)
  2. 上位人気で凡走した馬が、馬場のどこを通ったか(断然人気が飛ぶときは通った馬場が悪いことが多い)
  3. 2で見た馬が次走で巻き返したか(巻き返せば「前走は馬場が不利だった」の裏付け。また凡走なら不調など別の理由を考え直す)
- **ゴール前の隊列**で簡単に分かる
  - 前有利・内有利: 内の逃げ・先行が残り、外の差しが届かない「縦長の三角形」
  - 外有利: 直線で馬群が凝縮し、内の先行馬が沈んで外の差しが横一線に広がってゴール(ターコイズSのような形)。前半のレースで外差しが多い日は信頼度が高い。未勝利のダートは後ろから来る馬がほぼいないので参考にしやすい
