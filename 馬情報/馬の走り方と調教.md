# 馬の走り方と調教(運動科学から見た競馬)

出典: YouTubeの講演動画(陸上競技連盟の科学委員長を務めた小林氏が、中央競馬会の依頼で行った研究の話。ユーザー提供の文字起こし、2026-10-21)を要約。数値は動画内の説明で未検証。

## 要点
1. **勝ち負けの約7割は血統、残り3割は育成・調教・餌など**
   - 以前の中央競馬会は「9割が血統」と考えていたが、良い血統でも走らない馬、血統が平凡でも勝つ馬が出るため、今は約7割と見ている
   - → 予想でも血統は大きな材料だが、それだけで決めない(シミュレーターの配点の考え方と同じ)
2. **速い馬の走り方は「前肢かきこみ型」**
   - 前脚をピンと伸ばして着く「伸展型」は、ブレーキが大きくピッチが遅い。前脚を素早くかき込む方が、小さな円で脚を回せてブレーキが少なくピッチが速い
   - 速く走るときほど、脚の軌跡は円に近い(きつい)形になる。楽な走りは平たい楕円。かき込むには前肢・胸の筋力と、動きの学習(調教)が要る
3. **腰(骨盤)が柔らかく、後ろ脚が前脚の近くまで踏み込める馬は速い**
   - お尻が出っ張ったまま(人の「馬腰」)だと後ろ脚が前に出ない。チーターのように腰が丸く動く馬が速い
   - 競馬中継で「腰が柔らかい」と言う解説者は、ここを見ている
4. **坂路調教**
   - 関西馬が関東馬に勝てない時代に、栗東がアメリカにならって坂路を作り(全長約1200m・高低差32m)、関西馬が強くなった
   - 美浦の坂路は物足りないとされ、**2023年10月に改修**(掘り下げて3%の坂の区間を長くした)。調教の時計は4ハロン(800m)で見ることが多い
   - 坂路は前肢のかき込みと、腰で後ろ脚を前へ運ぶ動きを鍛える
5. **その他**
   - 馬は人の真似をする。厩務員が背筋を伸ばして引くと馬の姿勢も良くなるため、パドックの引き方も指導されている(ただし厩舎によって違う)
   - プール調教は鍛えるだけでなく回復にも使う。レース後の休養(間隔)の取り方も大事

## 血統の歴史(同じ講演シリーズの別回、2026-10-21)
大部分は日本の在来馬(木曽馬・道産子・対州馬など、ルーツはモンゴル馬が対馬経由で入ったもの)の話で、予想には関係しないため省略。
- サラブレッドはアラブ馬とイギリス在来馬の交配で作られ、父系をたどると3頭(ダーレーアラビアン・バイアリーターク・ゴドルフィンアラビアン)に行き着く。血統書がない馬はサラブレッドと認められない
- 日本の主流はノーザンテースト → サンデーサイレンス → キングカメハメハの流れ。今の種牡馬はほぼ2系統にまとまる
  - ヘイルトゥリーズン系(サンデーサイレンス・ロベルト): ディープインパクト・キズナ・ハーツクライなど
  - ミスタープロスペクター系(キングカメハメハ): ドゥラメンテ・ロードカナロア・ルーラーシップ
- 同じ系統どうしの交配が続き、出走馬が兄弟・いとこばかりになってきたため、主流の血(サンデー・ノーザンダンサー・ミスプロ)を持たない「アウトブリード」の種牡馬を入れる動きがある(2022年の導入例として馬名が出るが、文字起こしでは判別できない)
- 年代など(社台ファーム創業を1995年と言っている部分など)は文字起こしの誤りを含むので、使うときは JBIS などで確かめる

## シミュレーターへの反映
- 計算(自動補正)には入れない。腰の動き・かき込みは映像を見て主観で判断するもので、同じ基準で再現できない([予想で捨てる情報.md](予想で捨てる情報.md) のパドックの扱いと同じ)
- 美浦の坂路は2023年10月に改修されたので、美浦の馬の坂路時計を自己比較するときは改修前(2023年9月以前)の時計と比べない([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md) の調教の基準に追記)
- 「西高東低」の理由の1つが坂路のきつさなので、美浦の改修で東西の差が縮む可能性がある。関西馬の関東遠征 +2 は今のままにして、振り返りで関西馬の遠征成績が落ちていないかを確認する([競馬場の特徴_JRA10場.md](競馬場の特徴_JRA10場.md) に追記)
