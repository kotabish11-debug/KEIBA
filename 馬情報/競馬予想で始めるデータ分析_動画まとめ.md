# 競馬予想で始めるデータ分析 の動画まとめと検証

- 出典: YouTube「競馬予想で始めるデータ分析」(https://www.youtube.com/@競馬予想で始めるデータ分析)の全96本(2026-10-27に一覧を取得。ショート・ライブはなし)。競馬の話が多い25本の自動字幕を読んだ
- 動画内の数値は本人の説明で未検証。下の「検証」は 2017〜2026/3 の平場(重賞・障害を除く約40万頭、`自動実行/検証/holdout_eval.pl`)で、勝率を市場の勝率(単勝オッズから)と比べた結果
- ソースコード・電子書籍(note)の案内の部分は取り込まない
- 全体の印象: netkeiba のデータを Python でスクレイピングし、LightGBM で「1着に入る確率」を出し、単勝オッズを掛けた期待値で買う競馬AIを作る講座。96本の大半はプログラミングの手順(スクレイピング・前処理・クラス・pytest・VPS・自動投票・PyTorch・強化学習)で、予想の中身として新しく使えるのは少ない。考え方(期待値・確率の当たり方・買う点数とぶれ)は、このシミュレーターが既に払戻データで確かめてきたことと同じ

## すでに入っていたもの(二重に補正しない)

- 期待値 = 予測した確率 × オッズ。1を超えたものを買う(#20・#52 ほか)→ シミュレーターの買い方そのもの
- 期待値が大きく出る所ほど確率の見積もりが外れている(キャリブレーション、#21)・期待値の線は1より上で一番良い(単勝1.3〜1.7、馬連1.8など)→ 2026年の平場で確かめ、単勝10倍以上は期待値が高く出るほど外れていたので買わない、ワイドは期待値1.1以上に(検証.md の10〜12)
- 予測の当たり方(ログロス)を良くしても回収率は上がらないことがある。回収率に効くのは期待値1の前後だけ(#52)→ 重みは払戻データの回収率で確かめてから変えている(検証.md の10・11)
- 買う点数が少ないほど回収率がぶれる・シャープレシオ(#28)・回収率の幅(#31)→ simulator の convHint(何レースでプラスに近づくか・上振れ幅)
- 馬連の確率は Harville 式(#31: P(A1着・B2着)= pA × pB ÷ (1−pA))→ runSim と検証の3着以内率で使っている
- 1着だけを正解にすると、ハナ差の2着も「負け」として学習してしまう(#22)→ 重みの当てはめ(weight_fit.pl)は1〜3着の順番(Plackett-Luce)で見ている
- 脚質(#44): 逃げ・先行が有利、ダートは逃げがさらに有利、距離が長いほど差し・追込、千直は先行 → simulator の defaultBias・COURSE_PRESET
- 直近5走の同じ距離の最速タイム(#16)→ 自分のスピード指数の検証(検証.md の16、データ集め中)
- 騎手・調教師の過去成績(#15)→ 騎手の点はベイズ推定(検証.md の18)、オッズがあるときの上乗せは0
- 学習に使ってはいけないデータ(結果の後でしか分からない値、#27)・学習と予想の処理をそろえる(#37)・学習期間を時系列で分ける(#12)→ holdout_eval.pl で、条件を決めるのに使っていない期間で確かめている(検証.md の17)

## 検証して不採用・取り込まないもの

| 動画の主張 | 判断 |
|---|---|
| 馬番の方が枠番より効く(#19 の特徴量の重要度) | AIの中での重要度の話で、予想のルールにならない。枠の有利不利は既にコースごとに入っている |
| 出走数が効く(#19) | 市場が織り込んでいる(勝率の予想には効いても、オッズより当たる材料ではない) |
| 得意なコース・距離(Target Encoding、#25・#26)| 近い条件の「専用機の巻き返し」(カチウマ博士)が2017年以降0.91倍で外れた。距離・コースの成績は既に kyori・course の点にある |
| レースのクラスの分け方を直す(#41、リステッドを分けるなど)| 自分のAIのデータの直し方の話。このシミュレーターは重賞を手で作り、リステッドは平場の自動計算でオープンとして扱っている |
| 払戻が一定になるように賭ける(単勝適正回収値、#20)| 回収率のぶれを小さく見せる評価のやり方で、儲けが増える買い方ではない |
| 予測の当たり方より期待値1の前後に重みを置いて学習(#52)| 機械学習の学習のやり方。このシミュレーターの重みは5つしかなく、払戻での回収率で直接確かめているので同じ問題は起きにくい |
| 回収率122%・153%・162% など | 本人のAIのテスト期間の数字。期待値の線を後から選んでいて、選んだ期間の偏りが入る(検証.md の17 で見たのと同じ) |
| スクレイピング・自動投票・VPS・PyTorch・強化学習などのプログラミングの回 | 予想の中身ではないので取り込まない |
