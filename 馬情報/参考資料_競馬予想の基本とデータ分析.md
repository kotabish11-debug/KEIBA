# 参考資料：競馬予想の基本とデータ分析

- 出典: https://note.intimatemerger.com/n/n1a4098b95d83 (インティメート・マージャー note)
- 取得日: 2026-10-16
- 種類: 初心者向け入門記事(予想モデルや回収率の検証結果は載っていない)

## 要点

### 控除率
- 単勝・複勝でも控除率は約20%。何も考えずに買うと長期的には約2割負ける
- → シミュレーターでは「期待値(的中確率 × オッズ)が1を超える買い目だけ買う」考え方が必要

### 予想に使うデータ(記事で挙げられているもの)
- 競走馬の実績・過去のタイム
- 距離別・競馬場別の成績
- 血統
- 調教内容
- ローテーション(前走からの間隔・前走のレース)
- 当日の馬体重
- 馬体の特徴(例: 胴が長い → 長距離向き)、パドックでの馬体・毛ヅヤ・歩き方

### レースの傾向データの例
- 日本ダービー(2010〜2019年)の勝ち馬の前走: 皐月賞 8頭、京都新聞杯 2頭、それ以外 0頭
  → 「前走のレース」は大レースで強い絞り込み条件になる
- コースごとの傾向: 内枠の成績、直線が短いコースでの逃げ切りの多さなど
  (→ [競馬場の特徴_JRA10場.md](競馬場の特徴_JRA10場.md) と組み合わせて使う)

### 券種
- 単勝・複勝・応援馬券・枠連・馬連・馬単・ワイド・三連複・三連単の9種類、100円から
- 初心者には単勝・複勝が勧められている(当たりやすく、控除率も低め)
- 単勝オッズ = 人気順。オッズが低いほど勝つと見られている

### 分析ソフト(参考)
| ソフト | 特徴 |
|---|---|
| TARGET | JRA-VANの定番ソフト。機能が多く自分で予想したい人向け |
| Cross Factor | 複数サービスのデータを掛け合わせて独自の予想ロジックを作れる。プログラミング不要 |
| ゴールドジェネレーター | JRDBデータを分析(JRA-VAN非対応) |
| 馬王Z | SQLで予想ロジックを作り自動投票まで可能 |

## シミュレーターへの活かし方(メモ)
- 「前走のレース」「距離・コース別成績」「馬体重の増減」は、今の出走馬データに項目として入れる価値がある
- 買い目は控除率を超える期待値が見込めるときだけ出す。見込めないレースは「見送り」と表示する
