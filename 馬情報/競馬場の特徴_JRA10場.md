## コースを読む6つの規則性(2026-10-21追加)
出典: YouTube「上昇」の競馬場攻略の動画(ユーザー提供の文字起こし)を要約。数値・一覧は一般的な知識で補った概略なので、JRA公式のコース紹介で照合すること。

1. **回り(右・左)**: 右回りは8場、左回りは東京・新潟・中京の3場。東京で行われるG1が多い(ダービー・JC・天皇賞秋・オークス・安田記念など)。左回りでしか走らない馬もいる(例: ウオッカはG1・7勝のうち6勝が東京)
   - 見る点: 今回と同じ回りで好走があるか / 初めての回りではないか / 好走がどちらかの回りに偏っていないか
2. **直線の急坂**: 急坂があるのは中山・阪神・中京(東京も緩い上り)。平坦(新潟・小倉・京都・札幌など)で好走していた馬は、急坂コースで止まりやすい。急坂で好走した馬は平坦でも走れる
   - 危険な人気馬: 新潟・小倉で連勝 → 中山・阪神で1番人気
3. **スタートから1コーナーまでの距離**
   - 短い: 外枠は前を取りにくい → 内枠の逃げ・先行が有利。ペースが落ち着きやすい
   - 長い: 外枠でも前を取れる。位置取りが激しくなり、差し・追込にもチャンス
   - 同じ競馬場でもスタートが約200m後ろになるだけで逆になる。主な組み合わせ(短い → 長い): 中山 芝1800 → 芝2000 / 中京 芝2000 → 芝2200 / 中京 ダ1800 → ダ1900。ほかに京都 ダ1800 → ダ1900、阪神 ダ1800 → ダ2000 も同じ形。東京 芝2000 は1コーナーまでが短く内枠有利で有名
   - 狙い方: 短い方で届かなかった差し馬は長い方で、長い方で粘れなかった先行馬は短い方で狙う
4. **芝スタートのダート**: スタート付近が芝で、外側ほど芝を長く走れるので、**外枠が有利**(普通のダートは内枠有利なので例外)
   - 主なコース: 東京ダ1600(フェブラリーS)・中山ダ1200・阪神ダ1400・阪神ダ2000。ほかに京都ダ1400・中京ダ1400・新潟ダ1200・福島ダ1150
5. **関西馬(栗東)と関東馬(美浦)**: 「西高東低」で関西馬が強い(過去10年のG1勝利数は関西が関東の3倍以上、と動画では説明)。理由は栗東の坂路の方がきつい・有力馬主や大牧場の馬が栗東に集まる・有力種牡馬の産駒が多い
   - 関西の競馬場で5着前後の関西馬が、関東へ遠征すると相手が弱くなり勝ち負けになる
   - ただし美浦の坂路は2023年10月に改修されてきつくなった([馬の走り方と調教.md](馬の走り方と調教.md))。**2026年の重賞では、関東の競馬場での関西馬と関東馬の成績はほぼ同じで、人気どおり**だった。関西馬というだけで上げない(遠征 +2 はやめた)
   - 逆に、関東馬が関西の競馬場の重賞に出ると人気より走っていない(2026年: 勝ち8/期待10.6、複勝28/期待32.8。175頭なので参考程度)
6. **競馬場の格(出走馬のレベル)**: 関西メイン(京都・阪神) > 関東メイン(東京・中山) = 関西ローカル(中京・小倉) > 関東ローカル(新潟・福島)。札幌・函館は夏だけなので別扱い
   - 関西メインで好走 → ほかのメイン場でも通用しやすい
   - 関西メインで凡走 → 関東ローカルで一変することがある
   - ローカル(特に関東ローカル)で連勝 → 関西メインで人気になったら危険

組み合わせ例: 中山芝1800 = 右回り・急坂・1コーナーまで短い → 内枠の逃げ・先行が軸候補。

## 全10場を4つの見方で分ける(2026-10-21追加)
出典: YouTube「青木」(競馬副業のチャンネル)のJRA全10場の動画(ユーザー提供の文字起こし)を要約。予想で見るのは「能力があるか」と「その能力を発揮できるか」で、競馬場の知識は後者に使う。前走の競馬場と今回の競馬場の違いを見る(1場だけ深く知っても比べられない)。

| 見方 | 影響 | 分類 |
|---|---|---|
| ① コースの広さ(1周の長さ) | 狭いほどコーナーが多く、器用さ・立ち回りと内枠が大事。広いほど能力がそのまま出る | 大箱: 東京・阪神・京都・新潟 / 小回り: 中山・中京・福島(1周約1600mで最小)・小倉・函館・札幌 |
| ② コーナーのきつさ | きついほど外を回るロスが大きく内枠・器用さが有利。緩いほど外差しが届き、枠の差が小さい | 原則は広いほど緩い。例外: **新潟**は出口が急なスパイラルカーブ(外出しのイメージだけで外枠を買わない)/ **中京**はタイト(中京ダ1800は外枠がかなり不利)/ **函館はきつく札幌は緩い** |
| ③ 坂(直線) | 急坂はパワー、平坦はスピード | 急坂: 中山(JRAで最もきつい)・阪神・中京 / 緩い上り: 東京(持続力) / 平坦: 京都・新潟・小倉・函館・札幌・福島 |
| ③ 坂(道中) | 直線までにどれだけ消耗するか。下りがあれば自分で動けない馬も勢いで位置を上げられる | 中山: スタート直後にも急坂、高低差5.3mでJRA最大 / 京都: 3角で上り4角へ下る「加速装置」(京都巧者の理由)/ 函館: 高低差3.5mでローカル最大、意外とタフ / 札幌: 高低差約0.9mでほぼ平坦 / 小倉・福島: 平坦と言われるが小さな起伏あり |
| ④ 直線の長さ | 長いと位置取りの不利を取り返せ能力差が出る。短いと先行力・器用さ | 長い: 新潟(約659m)・東京・阪神外回り(右回りで最長)/ 短い: 中山・小倉・函館・札幌 |

**4つのグループ**(横軸=広さ、縦軸=直線の坂)
- 小回り・急坂: 中山・中京 → 立ち回りとパワー
- 大箱・急坂: 阪神(東京は坂が緩いので少し下)→ スピードとパワーの両方
- 大箱・平坦: 京都・新潟 → 乗ったスピードをどれだけ持続できるか
- 小回り・平坦: 小倉・札幌・福島・函館(函館は道中の坂でこの中では最もタフ)

**使い方**: 人気馬は「前走で力を出せた舞台と、今回の舞台で求められる適性が同じか」を疑う。人気薄は、能力を前提に「今回は力を出せる舞台か」で拾う。例: 小回りで器用さを生かして好走した馬が大箱に替わると、能力そのものが問われて負けることがある。直線の短いコースで上がり最速でも届かなかった馬は、長い直線で巻き返せることがある。

シミュレーターでは、全レースの自動計算(`race_json.pl`)で前走と今回の競馬場のタイプ替わりを補正している: 前走は平坦で好走・今回は急坂 -2 / 前走は急坂で凡走(4〜9着)・今回は平坦 +1 / 前走は小回りで好走・今回は大箱 -1(いずれも同じ馬場の前走だけ)。

## 阪神競馬場のコース別(2026-10-21追加)

- ダートは全体に**外枠有利**(砂をかぶらず揉まれない)。乾いてタフな馬場ほど強まる

## 東京競馬場のコース別(2026-10-21追加)
出典: YouTube「上昇」の東京競馬場の動画(ユーザー提供の文字起こし)を要約。

- 全体: 左回り。直線は芝約526m(新潟の次に長い)、ダート約501m(全場で最長)。直線に緩い上りがあるが、坂の経験は要らず平坦に近いと考えてよい。中山(機動力・立ち回り)とは逆の適性(スピード・瞬発力)が要る
- **直線が長くても差し有利ではない**。逃げ・先行の方が成績が良い。特に開幕1〜2週は前で競馬できない馬は届きにくい。秋開催は芝を張り替えて開幕するので、開幕直後は内枠が圧倒的に有利・外枠不利
- 左回りでの好走経験を必ず確認

| コース | 傾向 | 狙い目 |
|---|---|---|
| 芝1400 | 序盤が落ち着き前有利。1200mからの延長は不振 | 前走1600m以上からの短縮の逃げ・先行 |
| 芝1600 | 1400より差しが届く。地力が出る(阪神・新潟の芝1600と似る) | 阪神芝1600で好走した馬。中山芝1600で好走して初めて東京は危険 |

| 芝2400 | 最もフェア。総合力(スタミナ・瞬発力・持続力)と騎手の我慢 | 内枠の3〜4歳 |
| 芝2500 | 2400よりスタミナが要り、差し・追込の成績が良い | 長距離で好走経験のある差し・追込 |
| ダ1300 | 1角まで約300m。前有利で、ダートスタートのため内枠が良い | 内枠の逃げ・先行 |

## 東京・京都の別の見方(青木、2026-10-21追加)
出典: YouTube「青木」の東京競馬場・京都競馬場の動画(ユーザー提供の文字起こし)を要約。上の「上昇」の表と食い違う所は、両方を書いておく。

**東京**
- 東京は能力どおりに決まりやすい(大箱・緩いコーナー・長い直線で、位置取りや枠の小さな不利を取り返せる)。東京の適性(長い直線で緩い坂を上りながら脚を使い続ける)は、ほぼ能力の高さそのもの。予想は能力比較に時間を使う
- 小回りでコーナーが下手で力を出し切れなかった能力馬は、初めての東京でも狙える(例: 2026年青葉賞のタイダルロック)。逆に、器用さやパワーで他場を好走していた馬は東京で足りないことがある
- 後方一気ばかりは決まらない。前・中団も脚を残しているので、ある程度の位置取りは要る。芝は距離が長いほど逃げの勝率が上がる(1600<1800<2000)
- 芝1600: 1角まで500m以上で枠の差はほぼない。下級条件はスロー、上級条件は前半から速く総合力勝負。下級条件で勝った「コース適性」は上のクラスでそのまま通用するとは限らない
- 芝2000: 1角まで約130mで、外枠は外に振られる。1枠がかなり有利(天皇賞秋は直近5年、2桁馬番の3着以内なし)。内枠の先行馬がすんなり先頭に立つと残る
- 芝2400: 最もフェア。スローなら瞬発力(オークスはマイラーも来る)、早めのペースなら持続力(ダービー・JC)。JCは開催の最後なので馬場の傷み方を見る
- ダ1600: 芝スタートで外枠有利(内枠の強い馬が砂をかぶって崩れることも)。1200mからの延長より1800mからの短縮が好成績。コーナー2回で、1800mを立ち回りで好走してきた馬には厳しい
- 芝1400: 短距離馬が出てきて前半が流れやすく、直線一気になりにくい。ロスなく立ち回る持続的な競馬。トラックバイアスが出やすい

**京都**
- 京都の特殊さは3〜4角の下り坂(外回りで高低差4.3m)。下りで勝手に加速し、平坦な直線で押し切るので、問われるのは**後半の持続力**。自分でギアを上げるのが苦手な馬(東京のスローの瞬発力勝負で切れ負けした馬など)や、中山の小回りで脚を使わされた馬が京都で一変する(京都巧者が生まれる理由)
- 芝は外回りか内回りかをまず確認。外回りは下りから長く脚を使う競馬、内回りは前と内が有利
- 芝1600(外): 1角まで約710mで枠の差は小さい。馬群に包まれず外からスムーズに加速できる馬。東京・阪神のマイルとは適性が違い、リピーターが出やすい(マイルCS)
- 芝2000(内): 1角まで約310m。逃げの勝率は芝1800より高い(18.6%対15.5%)。ただし秋華賞のような上級戦は先行争いが激しく、内で溜めて短い直線で一瞬で抜け出す馬。外回りで長く脚を使って好走してきた馬を過信しない
- 芝2200(外): 下りからの持続力勝負。3角の上りで消耗するのでスタミナが要り、2400m以上からの短縮が好成績
- 芝3000・3200: 1角まで短いが距離が長く道中で位置を取り直せるので、枠はそれほど気にしなくてよい(「上昇」は内枠が圧倒的に有利としている。菊花賞の過去10年は外枠も好走)。ほぼ全馬が初めての距離でスローになりやすく、スタミナより能力と後半の持続力
- ダート全体: 内回りのさらに内側で直線が短く平坦なので前が有利。ダ1800は1角まで約280mで、内枠の先行馬がすんなり行けると有利。阪神(直線に急坂)で止まった先行馬が京都で粘る、逆に京都で粘った先行馬が阪神で差される

シミュレーターでは、京都芝1600・芝3000の枠の補正を小さく(0.2)、京都ダ1800を内枠寄り(0.3)、東京芝2000をさらに内枠寄り(1.0)にした。東京ダ1600の1200m以下からの延長は自動計算で -2。

## 補足(シミュレーターへの取り込み方)
- 競馬場・コース・距離ごとに、脚質の有利・不利を数値化して入れる
- 馬場状態(良・稍重・重・不良)で、洋芝や重馬場適性が変わる
- 枠順(内枠・外枠)の有利不利もコースで異なる
