# 新馬戦の見方

出典: YouTube「上昇」の新馬戦の動画(ユーザー提供の文字起こし、2026-10-21)を要約。数値は動画内の説明で、自分で検証したものではない。

## 見るポイント
1. **生まれ月が早い馬**: 2歳戦は1〜3月生まれが有利。勝率は1月生まれ約11%、6月以降約5%と2倍以上の差(JRAの研究でも1〜2月生まれの勝ち上がり率が高い)。生まれ月はオッズにほとんど反映されないので狙い目
2. **調教**: 新馬戦は比べる過去がないので、調教が一番の手がかり
   - 最終追い切り・1週前追い切りで**加速ラップ**(後半ほど速くなる)の馬は、余力がある証拠
   - **誰が乗ったか**: 調教助手は騎手より10kg以上重いことがある。重い人が乗って出した時計は価値が高い
3. **兄弟姉妹の新馬戦の成績**: 仕上がりの早さ(早熟性)は血統で似る。兄姉がデビュー戦から走っていれば、この馬も初戦から走りやすい。逆なら初戦は苦しいかも
4. **騎手×調教師のコンビ**: 新馬戦で特に成績が良い組み合わせがある(陣営が勝負できる馬を任せている)。動画の例(2019年以降の新馬戦): 横山武史×伊藤圭三(勝率28.6%・単回収358)、田辺裕信×久保田貴士(勝率22.7%・複勝率50%)、松山弘平×橋口慎介(勝率21.9%・単回収230)。年によって大きく変わるので、定期的に調べ直す
5. **前に行ける馬が有利**: 新馬戦はスローペースになりやすく、前の馬が止まらない。前に行けるかは次で見る
   - 陣営コメントの「スタートが速い」「二の脚が速い」(新馬戦では信用してよい)
   - 「前向きな気性」「行きたがる」は、新馬戦ではむしろプラス(嫌われる分オッズも付く)
6. **人気と馬体重**
   - 新馬戦の1番人気は強い(勝率38〜42%・複勝率71〜75%。全体は勝率約32%・複勝率約64%)。ただし1倍台は買い続けても増えない → **軸にはしてよいが、狙いは相手(ヒモ)**
   - 馬体重: 大きい馬が有利。ダートは500kg以上の3着内率が30%超で、460kg未満と差が大きい。芝は460kgが境目。ただし小柄な馬は嫌われすぎて、回収率では上回ることがある

## シミュレーターへの反映
- 全レースの自動計算(`自動実行/全レース/race_json.pl`): 新馬戦は馬体重で `jisseki` を補正(ダート500kg以上 +3・460kg未満 -3、芝460kg未満 -2)。馬体重は当日発表なので、当日の更新から効く
- 1番人気の扱い: シミュレーターは期待値(オッズ×確率)で買い目を選ぶので、人気馬の単勝は自然に外れ、相手狙いになる
- 生まれ月・調教・兄弟・騎手×調教師・陣営コメントは自動では取れていない。重賞(2歳重賞を含む)で手で能力値を付けるときに使う(基準は [レースデータの作り方.md](../シミュレーター/レースデータの作り方.md))
