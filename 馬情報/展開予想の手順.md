# 展開予想の手順

出典: YouTube「青木」の展開予想の動画(ユーザー提供の文字起こし、2026-10-21)を要約。宣伝・勧誘の部分は除いた。

## 考え方
- 予想で見るのは「能力があるか」と「その能力を今回発揮できるか」。展開は後者を左右する要素の一つ
- 展開だけを根拠に買わない(「差しが決まりそう」で後ろの馬を手当たり次第に買うのは予想ではない)。能力に対して展開がどれだけ追い風・向かい風かを足し引きする
- どの馬が逃げるかを完全に当てるゲームではない。細部がずれても「流れ(速い・遅い)」の大枠が合っていればよい(例: 2026年皐月賞は逃げ馬の読みは外れたが、競り合いなしのスローという流れは合い、本命のロブチェンが勝った)

## 3つのステップ
1. **逃げ・先行馬を見つける**
   - 近走の通過順(前にいたか)と**テンの速さ(前半3F)**を見る。同じ「前走逃げ」でも前半3F 32.9秒と34.2秒では、速い方が先手を取る(同じ日・同じ場・同じ距離なら比べやすい。馬場・コースで時計は変わるので単純比較はしない)
   - 斤量が軽いほどスタートダッシュがつきやすい
   - レース映像はスタートから1コーナーまでを見る。楽にその位置を取れたのか、押して押してやっと取れたのか
2. **並びを想像する**
   - 同じくらいの速さなら内枠が先手を取りやすい。外枠は内をかわすために脚を使うか、外を回らされる
   - **スタートから1コーナーまでの距離**: 短いと外枠が前に行く時間がない。長いと外枠でも内をかわして先手を取れる
   - 出遅れがちだが加速すると速い馬は、内枠だと包まれやすく、外枠の方が巻き返しやすい
   - 差し馬も、内で前が壁になるのか、外からスムーズに動けるのか、外を回され続けるのかを見る
3. **流れを判定する**
   - 行きたい馬が複数いて競りそうなら速くなる。1頭だけなら落ち着く
   - 「1000m通過○秒」のような絶対の基準はない(クラス・距離・メンバーで変わる)。このメンバーの中で相対的に見る
   - **逃げないと走らない馬**は、不利な枠でも無理に行くのでペースを上げる
   - **短い距離から延長してくる先行馬が多い**と前半が速くなりやすい(差し・追込の延長組は関係ない)
   - 速い流れ → 前が苦しく差しが届く。遅い流れ → 前も脚を残すので後ろは物理的に届きにくい
- 夏のローカル(小回りで能力差が小さい)ほど展開の影響が大きい

## シミュレーターへの反映(2026-10-21)
- ペースの自動見積もり(ハイ・ミドル・スローの確率)は、これまで逃げ馬・先行馬の頭数だけで決めていた。次を足した
  - 逃げにこだわる馬(近3走で2回以上、最初のコーナーを先頭で通過)が2頭以上 → ハイペースの確率 +10%
  - 前走より200m以上の延長で逃げ・先行の馬が3頭以上 → ハイペースの確率 +5%
- 目印は全レースの自動計算(`race_json.pl` の `mustLead`・`fromShort`)が付ける。重賞で手で作るレースデータにも、同じ名前で `true` を書けば効く
- 枠と1コーナーまでの距離は、コースごとの枠の補正(`drawBias`・`COURSE_PRESET`)で扱っている
- 追加(同日): 逃げないと走らない馬(`mustLead`)自身は、ハイペースの回で -1.5(競られて崩れる)、スローの回で +1(楽に行けて粘る)
- 追加(同日): 福島・小倉・函館・札幌(小回りのローカル)は、ペースによる脚質の有利・不利を 1.25 倍にする

## コタの「展開と隊列を読む方法」(2026-10-22追加)
出典: YouTube「コタ」(ネット競馬のプロ予想家)の展開講義(ユーザー提供の文字起こし)を要約。宣伝・勧誘の部分は除いた。数値は動画内の説明で、下の「検証」以外は未検証。

### 動画の主張
- 着順は少しのロスで入れ替わる(2024年有馬記念はレガレイラがシャフリヤールにハナ差。16番枠でなければ逆だった、という見立て)。人気薄が来るときはスムーズに走れていて、1番人気が飛ぶときは包まれるなど不利を受けていることが多い
- **逃げ馬のすぐ外の馬を探す**: 逃げ馬が前に出ると外の馬は前と内に進路ができる。内の馬は、外から切れ込む逃げ馬に巻き込まれやすい(例: 2024年ベテルギウスS、3番枠のミトノオーが逃げ、16番枠のサンデーファンデが9番人気で勝利)
- **先行馬の数**: 前走の1コーナーで3番手以内だった馬を数える。全体の40%以上ならハイペース寄り、30%未満ならスロー寄り(2024年有馬記念は1頭だけで、スローになった)
- **先行馬の並び**: 先行馬が隣り合う(例 3・4・5番)と競り合い・共倒れしやすく不利。ばらける(例 1・5・10番)と共存して楽に前へ行ける
- **最初のコーナーまでの距離**: 短いコースでは外枠の先行馬は外を回されるか無理に出すしかなく、逃げの狙いは内枠から
- **ローテーション**: 距離延長の馬は前走の速い流れを経験していて行き足がつく。延長の馬が4〜5頭いると先行争いが激しくなる。短縮の先行馬だらけの中に延長の馬が1頭だけなら、その馬が前へ行ける
- **斤量**: 前走より軽いとスタートダッシュにプラス、重いとマイナス
- スローは前・ハイは差しが有利。まくり(道中で一気に位置を上げる)はハイでは消耗が大きく、スローなら届きやすい
- 前に行く馬は回収率が高い(1角1〜3番手は単複プラス)が、前走で前に行った馬をまとめて買っても回収率はマイナス。儲かるのは「普段は前に行けない馬が前へ行けたとき」。狙いの4型: ①斤量減+メンバーのテンが遅い ②近走でまくった(失敗すると大敗して人気が落ちる) ③距離延長(前走1角3番手以内が30%未満のスロー見込みのレースだけ) ④両隣が逃げ・先行の馬に挟まれた馬(内にも外にも出しやすい)
- 差し馬は2種類: 道中で動いていく「まくりの差し」(2024年エリザベス女王杯までのレガレイラは直線だけの差し、有馬記念では早めに動いた)と、道中は動かず直線だけの「普通の差し」(ダノンデサイル)。ハイペースなら普通の差し、スローならまくりの差しを狙う。3連系の上級条件では、3着以内に差し・追込が1頭は入ることが多い

### 検証(2026年8月30日〜10月19日の平場。8頭以上で、出走馬の7割以上に前走の通過順がある328レース)
人気ごとの3着以内率を基準に、条件に当てはまる馬が期待より何pt多く(少なく)3着以内に来たかを見た(集計: 自動実行/全レース/backfill.sh で集めた馬柱と結果)。

| 主張 | 結果 | 採否 |
|---|---|---|
| 前走1角3番手以内が40%以上ならハイ | 3着以内の馬の4角位置(頭数比)は40%以上 0.330・30%未満 0.332 で差なし | ペースの見積もりは変えない |
| 距離延長はスロー見込みのときだけ | 前走より200m以上延長の馬: 30%未満のレース +2.0pt(695頭、単勝回収率154%)、40%以上 -4.2pt(151頭) | **採用** |
| 逃げ馬のすぐ外が恵まれる | 逃げ候補(近3走の1角位置が最も前)のすぐ外 -6.0pt(169頭)。外全体 -2.2pt・内全体 +1.2pt と逆 | 不採用 |
| 両隣が前に行く馬 | -2.1pt(71頭) | 不採用 |
| 先行馬がばらけると有利 | 隣り合う先行馬 +2.2pt(282頭)・ばらけた先行馬 -1.2pt(546頭)と逆 | 不採用 |
| 斤量減はプラス | 斤量減 -2.2pt(818頭)、斤量減+前走1角6番手以下 -2.5pt。減量騎手の起用などで弱い馬が多いと見られる | 不採用 |
| 近走でまくった馬 | 全体 -2.6pt(195頭)、スロー見込みでも -2.2pt | 不採用 |
- 平場だけ・約2か月の集計で、重賞は入っていない。次に検証するときは期間を延ばす

### シミュレーターへの反映
- `race_json.pl`: 各馬に `prevFront`(前走の最初のコーナーで3番手以内なら true、それ以外は false。通過順が無ければ出さない)を出す。8頭以上で7割以上の馬に通過順があるとき、前走より200m以上の延長の馬は、`prevFront` が30%未満なら `choshi` +1、40%以上なら -2(東京芝1400・東京ダ1600の延長の補正がある馬は重ねない)。note に「距離延長・前に行く馬が少なく落ち着きそう(+1)」などと出る
- `simulator.html`: 予想の文章に「展開と隊列」(前走1角3番手以内の頭数と割合、補正を受けた延長馬、逃げ候補)を表示。能力値・買い目は変えない
- 手で作る重賞: 前走が近い(おおむね2か月以内)馬だけ `prevFront` を書き、同じ基準で延長馬の `choshi` を ±する(天皇賞秋で反映。菊花賞は全馬が延長なので差がつかず変えない)
