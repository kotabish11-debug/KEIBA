# 馬券の買い方: 単勝・馬連・馬単

出典: YouTube「青木」(競馬副業のチャンネル)の5本「単勝だけで競馬は勝てる」「馬単の使い方」「馬連1点で当てる方法」「一生使える軸馬の選び方」「3着以内に入る馬を見極める方法」(ユーザー提供の文字起こし、2026-10-21)を要約。LINE・勉強会・資料プレゼントの宣伝部分は除く。数値・配当は動画内の説明で未検証。馬名は文字起こしからの推定を含む。
3連複・ワイドは [馬券の買い方_3連複.md](馬券の買い方_3連複.md)・[馬券の買い方_ワイド.md](馬券の買い方_ワイド.md)。

## 共通の考え方
- 予想の本質は2つだけ: **その馬に能力があるか** と **その能力を今回発揮できるか**。知識(適性・時計・騎手・血統・展開・馬場)はどちらかに結び付けて整理する
- 能力は着順ではなく**レースの中身**で見る(相手の強さ・楽な逃げなどの恵まれ・不利・きつい流れ)。人気は着順の印象で決まるので、「着順は良いが中身は薄い馬」「着順は悪いが中身は良い馬」に気付けるほど期待値が取れる
- 能力は近走の平均ではなく**一番良かった走り(上限)**で見る。そのうえで、その走りをした時と今回の条件(競馬場・距離・展開・枠・馬場)を照らし合わせる
- 縦の評価(1頭ずつ、ほかと比べずにプラスとマイナスを出す)と横の比較(並べて順位を付ける)を**分けて**やる。一緒にやると「消したい」「面白い」という結論ありきになる
- 1つの不安だけで消さない(坂・初距離など)。総合的・相対的に評価する
- 項目ごとに点数を付けて合計する方法は勧めない(枠と展開、斤量とスタートなど、要素が絡み合っているため)。理由を言葉にして決め切る。言葉にできないレースは買わない
- 点数を増やすのは的中率を上げる行為で、当たったときの回収は薄まる。**基本は1点**、不確実性をカバーしても回収できるときだけ広げる

## 単勝: 1〜5番人気から1頭
- 2021〜2025年のJRAで、**勝ち馬の82.8%が1〜5番人気**。見る範囲を5頭に絞り、その中から1頭を選び切る
- 単勝は1点なので資金を集められる(1000円で5倍なら5000円。3連複25倍を200円で当てるのと同じ)
- 例(2026年セントウルS): 1番人気フリッカージャブ(スプリントの総合力が高い・内枠で前に付けられる、坂は不安)、ピューロマジック(直近2連勝は楽な逃げで恵まれた・坂で成績が落ちた履歴・前走がベスト条件)、ダイヤモンドノット(能力は最上位だが初の1200m・高速馬場への対応)を比べて、フリッカージャブを1番上に。最後はオッズで買うか決める

## 馬単: 人気同士でも回収できる
- 1番人気が本命で相手が3・4番人気のような人気同士でも、馬単なら6〜7倍以上、10〜20倍つくことが多い
- 馬連は「Aの方がBより上」という判断を馬券に反映できない。**どちらが1着かまで評価できたときは馬単**(当たれば配当が上がる)
- 単勝よりもうかり、3連単より当てやすい(3連単20点で200倍=2万円 と 馬単2点で20倍=2万円 なら馬単の方が現実的)
- 手順
  1. **上位と下位の差を確認**(1〜2着に来そうな馬と、それ以外に差があるレースか)。ここでは能力だけを見て、適性は考えない。差がない混戦は買わない
  2. **上位馬同士の順位付け**: 一番良い走りの条件と今回の条件を照らし合わせる。**直接対決**は最高の材料だが、先着したかではなく中身(位置取り・上がり・不利・その日の展開がどちらに向いたか)で見る
- 能力が1頭だけ抜けている馬は多少条件が向かなくても押し切るが、たいてい1番人気で割に合わない。能力差が小さいときほど条件の差で順位が入れ替わる
- 例: 2026年8月の中京芝1200m(2勝クラス)。1番人気トップアタックは前走の5着が内枠・前有利の馬場に恵まれたもの、今回は坂のあるコース。2番人気フォーゲルは前走で折り合いを欠いた負け、今回は外枠で末脚を生かせる条件好転 → フォーゲル→トップアタックの馬単12.9倍(馬連は6.4倍)
- 例: 2026年8月の中京ダ1800m(オープン)。1番人気トリポリタニア(先行力があり、位置取りが大事な中京1800mがベスト。6か月の休み明けは気になる)から、2・4番人気を消して馬単2点 → 25.6倍

## 馬連1点: レース選びで決まる
- 1点で勝負できるのは「2頭の好走率がとても高く、その2頭とほかの馬にはっきり差があるレース」。1日に1〜2レース程度。決まらないレースは見送る
- **不確実性が少ないレースを選ぶ目安**
  - **2勝クラス以上**(キャリアがあり、能力を比べやすい)。新馬・未勝利・1勝クラスは成長や力の再現性が読めない
  - **上位人気の馬にはっきりした好走歴がある**。ただし上位の1頭が長期休み明け・初めての距離やコースなら、そのレースは避ける
  - **競馬場**: 東京や阪神外回りのような、コーナーが緩く直線で巻き返せるコースは能力で決まりやすい。ローカルの小回りなどトリッキーなコースは位置取り1つで着順が変わるので向かない
  - **馬場**: 天気の変わり目・馬場の傷み具合が読みにくい日は避ける
- 人気同士の馬連5倍でも、1点に集めれば1万円が5万円。5点に分けると3倍が当たっても6000円
- 例(2026年6月の東京ダ1600m・2勝クラス): 1〜4番人気が10倍以下。1番人気ロンギングフォーユー(前走は出遅れから無理に2番手へ付けて、後に好走する馬を完封。唯一の負けは砂をかぶったときで、今回は外枠で砂をかぶらず芝スタート)、スマートスピア(後にオープンへ上がる馬と同タイム。前走はつまずき・詰まりで度外視)の2頭。3番人気は能力を出し切れる条件でも勝ち切れず今回は内枠、4番人気は負かした相手のその後が伸びず距離短縮 → 馬連1点4.6倍(馬単7.8倍も併用)

## 軸馬の選び方(人気馬から減点方式)
- **券種を先に決める**(回収率が上がらないうちは): 勝ち切る力(単勝)・2着以内の安定(馬連)・3着以内の安定(3連複・ワイド)で、軸に求める条件が違う。来そうな馬を選んでから券種を決めると「単勝で2着・馬連で3着・3連複で4着」が起きる。慣れたら、来そうな馬を言葉にしてから期待値の高い券種を選ぶ
- **1〜5番人気から選ぶ**。5頭が全部飛ぶことはまれ。穴は3連複の2列目・馬連の相手で絡めればよい
- **減点方式**: 人気馬はどれも良い所ばかりなので、良い所で選ぶと迷い、一番目立つ1番人気に飛びついて不安が出て負ける。不安で引いていき、減点の一番少ない馬を残す
  - 不安の例: 得意条件からの変更(人気馬は基本マイナス。不振の馬が得意条件に戻るのはプラス)、展開の不利(ほかにも逃げ馬・開幕週のスローで後方の差し馬)、出遅れ癖・揉まれ弱さ(内枠・ダートの砂かぶり)、近走の違和感(相手が弱かった・オッズが売れすぎ)、乗り替わり・休み明け・調教が軽すぎ
- **数字と中身で判断**: 着順より**着差**(2着で0.5秒差より7着で0.2秒差の方が良いこともある)、**タイム**(馬場補正したネット競馬のタイム指数が手軽)、位置取り(前で決まったレースを後ろから3着は評価)、再現性(枠・馬場・季節が変わっても走れるか)、**レース映像**(見る人が少ないので差になる)。インパクトだけで強いと決めつけない
- **期待値で最終調整**: 迷ったらオッズを掛ける。単勝5倍と10倍なら、好走率に2倍の差がなければ10倍の方が得
- 外すのを怖がって1・2番人気ばかり選ばない。目的は当てることではなく、長期で利益を出すこと

## 3着以内に入る馬の見極め(初心者向けの基本)
- **1〜3番人気から選ぶ**: 2020〜2024年のJRA全レースで複勝率は1番人気64.5%・2番人気51.9%・3番人気41.7%。3頭のうち1頭は3着以内に来るのが基本で、3頭とも消えるのは珍しい(2025年のG1は全レースで1〜3番人気のどれかが3着以内)
- **近走の着差**: 前走で勝ち馬と**0.5秒差以内**の馬が信頼できる。2〜3走続けて0.5秒差以内ならなお良い(1秒差の2着より0.2秒差の7着)。例: 2026年6月の東京・日野特別は、前走0.6秒差の1番人気(2.0倍)と、前走は同タイムでもその前が1.5秒・1秒差の3番人気が着外。2走続けて0.1秒差以内の2番人気が2着
- **同じ条件の実績**: 競馬場・距離・馬場状態が今回と同じで好走した馬。初めての条件は人気馬にとってはリスク(例: 2026年6月の函館日刊スポーツ杯は、函館芝1200mで勝ったことのある1番人気が勝ち、函館が初めての2・3番人気は4・5着)
- **それでも迷ったら**: 先行馬(4角10番手より前の馬の方が成績がはっきり良い)・同じクラスの経験がある馬(**昇級初戦**は前走の勝ちで人気しやすい)・**前走の圧勝は割り引く**(条件がはまっただけのこともあり、人気しすぎる)・安定感(1着と10着の繰り返しより2・3着の繰り返し)
- 穴を狙うときも、まず人気馬の信頼度を測る(人気馬が信頼できないから穴に余地がある)

## シミュレーターとの関係
- 能力値(実績・距離・コース・調子・騎手)を出してから、シミュレーションで全馬を同時に比べる流れは、「縦の評価→横の比較」と同じ形。ただし能力値は点数の重み付けで出している(青木の勧めない方法)ので、**数字だけで決めず、重賞で手で付けるときは各馬の `note` に理由を言葉で書く**([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md) のとおり)
- 単勝の「1〜5番人気」は、単勝を4〜9.9倍中心で選ぶ仕組み(長期の回収率が一番高い帯)とほぼ重なる
- 追加したこと(simulator.html の `trioHint`。予想の文章の「3連複の向き」):
  - 2着以内の確率で上位2頭が抜けているとき、**2勝クラス以上(重賞・オープン含む)で東京か外回りのコース**なら「馬連1点で勝負しやすい条件」、小回りのコース・下のクラスなら「1点勝負は控えめに」と添える
  - その2頭の勝率に1.6倍以上の差があれば「A→Bの馬単も向く」と添える
  - 1番人気の不安材料(favRisks)に「前走の圧勝(昇級初戦)」を加えた(★の判定には入れない。能力値は前走0.5秒以上の完勝で +2 しているので、動画の「割り引く」とは逆。期待値は市場のオッズと比べて出すので、人気しすぎの分はそこで調整される。振り返りの記録で、完勝した1番人気の成績を確かめてから能力値の扱いを決める)
  - 着差(0.3・0.5秒差以内の加点、2・3着でも離された減点)・近走の脚質・コースの成績は、全レースの自動計算(race_json.pl)ですでに入っている
  - 実際の買い目と金額は、これまでどおり期待値とケリー割合で決める
