# 軸馬と相手の選び方(減点方式のチェックリスト・相手選びの5つ)

出典: YouTube「上昇」の2本「軸馬の選び方(減点方式)」「相手選びで迷ったときの5つの選び方」(ユーザー提供の文字起こし、2026-10-21)を要約。LINE・予想AIの宣伝部分は除く。点数・成績は動画内の説明で未検証。
関連: [危険な人気馬と単勝の狙い方.md](危険な人気馬と単勝の狙い方.md)、[馬券の買い方_単勝・馬連・馬単.md](馬券の買い方_単勝・馬連・馬単.md)(青木の軸馬の選び方も減点方式)

## 軸馬: 減点方式で選ぶ
- どの券種でも結局は軸の精度で決まる。軸が決まらないから点数が増える
- 「前走1着・外国人騎手・血統が良い」のような**加点方式**は、良い材料だけを見て負ける原因を見落とし、過剰人気の馬をつかみやすい。競馬は「強い馬が勝つ」より「弱点の少ない馬が勝つ」
- 軸は**1〜3番人気**から(1〜3番人気のどれかが3着以内に来る確率は過去5年で91%)。3頭を並べてチェックリストで減点し、**減点の最も少ない馬**を軸にする。減点の多い人気馬は危険な人気馬として評価を下げる

### チェックリスト
| 点 | 項目 | 理由 |
|---|---|---|
| -5 | 前走逃げて好走 | 逃げは一番気持ちよく走れる形。同型がいる・マークがきつい・逃げられないと崩れる。逃げ馬は軸ではなく人気薄の穴で狙う |
| -5 | 初ダート・初芝 | 適性が未知(砂をかぶっても進むか)。初芝の回収率は非常に低い |
| -5 | 距離延長 | 短縮の方が回収率がはっきり高い。延長は馬が距離を長く感じ、折り合いも難しくなる |
| -5 | ダートで前走牝馬限定 → 今回牡馬混合 | ダートはパワーが要り牡馬が優勢。勝率約8% |
| -4 | 昇級初戦 | 相手が強くなる。連勝・圧勝・上がり最速は下のクラスだから成立した可能性 |
| -4 | 前走が重・不良(今回は良) | 好走が馬場の恩恵だった可能性 |
| -4 | 前走ローカル → 今回主要場(東京・阪神・京都など) | 夏以外のローカルは主要場の裏開催でレベルが低い。地方競馬場も同じ(砂が違う) |
| -3 | 6か月以上の休み明け | 5回に1回も勝たない |
| -3 | 芝の外枠(16頭以上の13番より外)/ダートの内枠 | 芝はコースロス。ダートは砂をかぶるのを嫌がる馬が多い(1〜3番人気でも枠で成績がはっきり違う) |
| -3 | ハンデ戦のトップハンデ | ハンデは能力差を縮めるためのもの。狙うなら斤量差を跳ね返す根拠(展開・得意条件)が要る |
| -2 | 急坂のコースで好走歴なし | 平坦で好走していた馬は坂で止まりやすい |
| -2 | 馬体重 ±15kg以上 | 成長・仕上げ・輸送・体調、いずれにしても怪しい(オッズにも入りやすいので小さめ) |
| -1 | 右回り・左回りの初めて/偏り | 利き手のように得意な回りがある |
| -1 | 冬の牝馬・夏の牡馬 | 牝馬は夏に調子が上がり、牡馬は体が大きく熱を逃がしにくいので夏が苦手 |

- 例: 2025年チャンピオンズC。1〜3番人気で減点の最も少ないウィルソンテソーロが2着、減点の多かった1番人気は13着(動画の説明)

## 相手: 迷ったときの5つの選び方
1. **軸と同じ脚質**: 逃げ馬を軸にしたのはスローで粘ると読んだから → 相手もその近くの先行馬。差し馬を軸にしたなら相手も差し・追込。例: 2026/6/21 白鷺S(阪神芝1600)は1番人気の差し馬エコロアルバを軸にすれば、差してきた人気薄も拾えた
2. **そのコースの実績**: 同じくらいの評価で迷ったら、今回のコースで好走歴のある方(白鷺Sの1・2着はどちらも阪神芝1600の勝ち馬)
3. **軸と枠が近い馬**: 内枠の軸が好走する日は内有利で、同じ進路を通る近い枠の馬も来やすい。芝の開幕週は内枠の先行馬でそろえる。**ダートは別**(内枠は砂をかぶる。迷ったら外枠)
4. **理由を説明できるデータだけ**: 「この重賞は2枠がよく来る」のような理屈のないデータはオカルト。コースの形から説明できるもの(中山芝2200は1角まで長く急坂を2回上るので差し有利、東京ダ1600は芝スタートで外枠有利など)を使う
5. **迷ったら人気のない方**: オッズを決めているのは自分と同じ馬券の買い手。人気を外して来られる方がダメージが大きい

## シミュレーターへの反映(2026-10-21)
- **軸の減点**(simulator.html の `axisHint`): 予想の文章に「軸の減点(1〜3番人気)」を出し、3頭の減点と理由、減点の最も少ない馬を示す。-8点以下の人気馬は「危険な人気馬の可能性」。能力値には足さない(下の自動計算・不安材料と二重にしないため、比べるための表示だけ)
  - 全レースの自動計算(race_json.pl)が各馬に `axisCheck`(理由と点数)を出す。チェックリストの全項目を見るが、データの制約で次のように近似している: 初芝・初ダートは「近走に経験なし」、昇級初戦は1〜3勝クラスで前走1着の馬だけ(オープン・重賞は前走のクラスが分からない)、牝馬限定は前走のレース名に「牝」がある場合だけ、急坂・回りは近走だけで判定、ダートの内枠は1〜3番
  - 手入力の重賞は、note・馬番・馬体重から分かる項目だけ(前走逃げて好走・前走道悪で好走・休み明け・枠・馬体重)。重賞で手で付けるときは、1〜3番人気に `axisCheck` を書いてもよい([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md))
- **相手の1と3**(同じ脚質・近い枠はセットで来る): シミュレーションで展開(ハイ・ミドル・スロー)を全馬に同時にかけているので、同じ脚質の馬は一緒に来やすく出ている。枠については、1回ごとに「その回は内が伸びる/外が伸びる」という全馬共通の揺れ(`DRAW_SHOCK`: 芝 2・ダート 1.2)を足し、枠の近い馬が一緒に来やすくした。平均の有利不利は変えない(固定の枠の補正 `drawBias` はそのまま)
- **相手の2**(コース実績)は能力値の `course` で入っている。**4**は採点基準の考え方と同じ(理由のないデータは使わない)。**5**(迷ったら人気のない方)は、期待値で買い目を選ぶので自然にそうなる

## テスラ「軸馬の選び方 4ステップ」(2026-10-21追加)
出典: YouTube「テスラ」の「軸馬を勘に頼らず選ぶ4ステップ」の回(ユーザー提供の文字起こし)を要約。チャンネル登録・AIの宣伝部分は除く。数値は動画内の説明で未検証。

- 軸が3着以内に来なければ、相手をどれだけ当てても全部外れる。勝ち負けは相手選びより**軸の精度**で決まる(軸の3着以内率40%なら10レース中6レースは相手に関係なく外れ、70%なら3レース)。予想の時間の大半は軸に使う
1. **先に券種を決める**: 券種で軸に求める条件が変わる
   - ワイド: 3着以内の**安定感**(1番人気でも勝つときと大敗するときの差が大きい馬より、5番人気でも毎回3着以内の馬)
   - 馬連: 2着以内の**確実性**(勝率は低くても2着以内率が高い馬。勝つときは強いが負けると大きく崩れる馬は不向き)
   - 3連複: 3着以内の**再現性**(前走1着でも今回コース・距離が変わる馬より、前走3着でも同じ条件で毎回3着以内の馬)
   - 同じ券種の中では基準を変えない
2. **人気馬を消去法で絞る**(良い馬を探すのでなく不安な馬を外す): ①距離・コース・馬場が前走から大きく変わる ②展開や枠が向かない(同型の先行馬が多い、得意な形に持ち込めない枠) ③前走以上が見込めない(相手が弱かった・展開が向いただけ) ④人気を集めすぎてオッズが見合わない
3. **数字と中身で1頭に決める**(候補2頭くらいから): 前走の中身(同条件の他レースと比べたタイム、着差は力か展開か)/同じ条件での実績/オッズが見合うか。軸は前日までに決める
4. **当日の馬体重・パドックで最終確認**し、不安が出たらそのレースは見送る
- やってはいけない: 好きな騎手・馬を気分で軸にする、根拠なく直前で軸を変える、軸を2頭にして絞る意味をなくす

### シミュレーターへの反映
- **1(券種で軸の基準を変える)**: simulator.html の `axisHint` の末尾に「券種別の軸」を追加。1〜3番人気のうち、シミュレーションの2着以内率が最も高い馬を馬連の軸、3着以内率が最も高い馬をワイド・3連複の軸として示す(同じ馬なら1頭)。買い目そのものは券種ごとの的中確率と期待値で選んでいるので、計算は変えない(表示だけ)
- **2・3**は既存の仕組みと同じ: ①条件の変化は上昇の減点(初芝・初ダート・距離延長など)と race_json.pl の距離・コース適性、②展開は展開予想と枠の補正、③前走の中身は favRisks の「前走の圧勝」とレースデータの作り方.md の前走の中身(±2)、④人気の集めすぎは期待値で自然に外れる
- **4(パドック)**は取り入れない: 情報収集の手順.md・予想で捨てる情報.md の方針(パドックは事前に決めた条件のときだけ使う)と同じ扱い。馬体重の大きな増減は既に自動計算と減点(±15kg)に入っている

## テスラ「3着以内に来る馬の見抜き方」(2026-10-21追加)
出典: YouTube「テスラ」の「前走の着順だけで選ぶと勝てない」の回(ユーザー提供の文字起こし)を要約。メルマガ・AIの宣伝部分は除く。数値は動画内の説明で未検証。

- どの券種も、狙った馬が3着以内に来なければ当たらない。人気別の3着以内率は1番人気 約60%超・2番人気 約50%・3番人気 約40%で、1〜3番人気のどれかが3着以内に来るのは9割超。ただし人気はみんなが見ているので、上位人気を買うだけでは利益が残らない
1. **着順ではなく着差**: 前走で勝ち馬と0.5秒以内の負けなら次走の3着以内率は約38%、0.6秒以上離された負けは約16%。着差の小さい負けで着順が悪い馬は、着順しか見ない人に嫌われて実力よりオッズが高くなり狙い目
2. **適性は距離と競馬場をセットで**: 同じ2000mでも競馬場が変わればコースの形・直線の長さが違い、求められるものが変わる(直線の長い広いコースは差しにも、小回りは前の馬に有利)。同じ条件の実績がなければ近い距離・似た形の競馬場で見る。それでも判断できなければ見送る
3. **追込馬は軸にしない**: 脚質別の勝率は逃げ 約15〜18%、追込 約1.7%で10倍近い差。追込は前が止まらないと届かず、展開という運に任せている。3・4コーナーで前にいた馬が3着以内に来やすい。軸は前に行ける馬
4. **前走の圧勝を疑う**: 1秒以上の差で勝った馬の次走の勝率は約14%で印象ほど勝てない(直前の目立つ結果が次も起きると思い込む「代表性ヒューリスティック」で人気しすぎる)。力が抜けていたのか、距離・馬場がはまっただけかを着差と適性で確かめる

### シミュレーターへの反映
- **3(追込は軸にしない)**: 軸の減点に「追込(展開待ち) -3」を追加(race_json.pl の `axisCheck` と、手入力の重賞用の simulator.html `axisChecks`)。点数は動画にないので独自(芝の外枠・休み明けと同じ重さ)。能力値は変えない(展開の補正と脚質×コースの補正で追込の届きにくさは既に入っているため、二重にしない)
- **1(着差)**は既に race_json.pl の choshi に入っている(4着以下でも0.3秒差以内 +4・0.5秒以内 +2、2・3着でも0.6秒以上 -2・1秒以上 -4)。動画の0.5秒/0.6秒の境目とも合うので変えない
- **2(距離と競馬場)**は能力値の `kyori`(この距離)と `course`(この競馬場のこの馬場)で入っている。「判断できなければ見送り」は期待値と見送りの基準で扱う
- **4(前走の圧勝)**は favRisks の「前走の圧勝」で既に表示している
- 人気別の3着以内率は市場のオッズから計算しているので補正しない
