# G1の高配当パターン

出典: YouTube「コタ」(ネット競馬のプロ予想家)の「G1完全ガイド この2パターンだけ押さえたらG1の高配当は9割以上取れる」(ユーザー提供の文字起こし、2026-10-22)を要約。数値は動画内の説明で、自分で検証したものではない。宣伝(指数表・LINE)の部分は省いた。

## 考え方
- G1で高配当(ここでは3連複1万円以上)を取るのに大事なのは、トップ騎手・G1実績・トライアルの強さで馬を選ぶことより、**そのG1で高配当が出るかどうかを先に見極めること**
- 高配当が出そうにないG1(動画の例: 2026年の宝塚記念)は、馬券は買わずに観戦だけでよい
- 高配当が出るG1の9割以上は、次の2つの型のどちらか

## 型1: 危ない1番人気だけが飛ぶ
- 1番人気には大量の票が入っているので、4着以下になれば外れ票を少数で分け合う形になり、**残りの上位人気から流すだけで高配当**になる。穴馬を探す必要はなく、2〜5番人気の能力・調子を普通に比べればよい
- 危ない1番人気の見分け方(動画の例: 2025年秋華賞のカムニャック。フローラS・オークス・ローズSの3連勝で1番人気→16着)
  - **前走で自己最高の走りをした後の反動**。前走の内容が過去のG1好走よりも上なら、次は落ちやすい(陣営にも防げない)
  - 毎回ほぼ完璧な騎乗で連勝してきた馬は、それが何回も続くとは限らない(動画でも半分は感覚と言っている)
- 結果は1〜5着が2・5・6・4・3番人気で、1番人気以外の人気馬がそのまま上位。3連単12万9850円
- ほかの例として動画が挙げたもの: 2025年有馬記念・2025年オークス・2024年有馬記念・2024年朝日杯FS

## 型2: 1番人気は堅く、2・3番人気が危ない
- 1番人気と、それに次ぐ力の馬は素直に買う。**2・3番人気がそろって危ないなら、3着はどの馬が来てもおかしくない**ので、3列目を穴馬まで広げた3連複・3連単が取りやすい
- G1はどの陣営も全力の仕上げで来るので、**2・3着に単勝50倍以上の大穴が来ることが多い**
- 動画の例: 2025年マイルCS(1着1番人気ジャンタルマンタル、2着4番人気ガイアフォース、3着15番人気ウォーターリヒト 130.2倍)
  - 2番人気ソウルラッシュ: 7歳でピークを過ぎた。その年の中山記念・安田記念・富士Sはいずれも3着で、上の2頭に**勝負付けが済んでいた**(世代交代の時期)
  - 3番人気アスコリピチェーノ: 1番人気の馬にはっきり負けていて、勝ったレースは相手が弱い。走りが大きく器用でないので、京都より東京向き(**コースの向き不向き**)
  - 2・3番人気は6・7着

## 残り1割: 1〜3番人気が全滅する大荒れ
- 1〜3番人気がすべて4着以下で3連複5万円以上の決着は、2021年〜2026年9月の平地G1 132レースで6レースだけ(5%以下)
- 事故のようなもので、狙う必要はない。外れても気にしない

## シミュレーターへの反映(2026-10-22)
- 予想の文章に「G1の荒れ方」を出す(`simulator.html` の `g1Hint`。グレードがG1のレースだけ)。1〜3番人気それぞれの不安材料を集め、どの型に近いかを示す。能力値・買い目は変えない
  - 不安材料: 1番人気の不安材料(`favRisks`)、軸の減点の合計が-5以下、能力値からの勝率が市場の8割未満、7歳以上(馬カードの性齢)、`note` の「反動」「勝負付け」
  - 不安材料が2つ以上、または強いもの(軸の減点-8以下・能力値の勝率が市場の7割未満・「反動」「勝負付け」)があれば「危ない」とする
  - 1番人気だけ危ない → 型1 / 2・3番人気だけ危ない → 型2(3着以内率8%以上の人気薄を3列目の候補に表示)/ 3頭とも危ない → 5%以下の大荒れなので見送りか少額 / どれも危なくない → 低配当になりやすいので見送り向き
- `favRisks` に `note` の「反動」を追加(1番人気の不安材料と★の判定の文章に出る)
- 重賞を手で作るときは、前走が自己最高の内容なら `note` に「反動」、上位人気の馬に何度も負けて勝負付けが済んでいる人気馬には「勝負付け」と書く([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md))
- 取り入れないこと: 型2での3列目の手広い穴流しを機械的に買い目にすること。人気薄の馬券は売れすぎやすい([馬券の買い方_3連複.md](馬券の買い方_3連複.md))ので、穴は期待値で選ぶ買い目のほうに任せ、表示は候補の目安にとどめる
- 以前の集計(「G1は1番人気の勝率が高い」[危険な人気馬と単勝の狙い方.md](危険な人気馬と単勝の狙い方.md))とは矛盾しない。G1の1番人気は全体としては堅く、その中で危ない1頭を見抜けたときが型1
