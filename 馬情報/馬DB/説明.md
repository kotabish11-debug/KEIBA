# 馬DB(競走馬・種牡馬・繁殖牝馬のデータベース)

2026-10-26 ユーザー指示「すべての競走馬、繁殖牝馬、種牡馬に関するすべての情報を集めて、常に新しい情報はないか調べておいて」で作った。
JRA公式(www.jra.go.jp/JRADB)の競走馬のページを全部たどって集める。数や進み具合は [概要.md](概要.md)(実行のたびに作り直す)。

## 集め方(自動)
- PCのタスク「競馬_PC収集」(毎日 10:20・16:20・22:20)の最後に `bash 自動実行/馬DB/update.sh` が毎回動く(Claudeは使わない。1回50分まで)。中身は [update.pl](../../自動実行/馬DB/update.pl)
- 2026-10-28〜 [loop.sh](../../自動実行/馬DB/loop.sh) を裏で動かし続け、50分取り込むたびに 馬情報/馬DB だけをコミットして送る。止めるときは state/stop を作る。動いている間はPCタスクの update.sh は「実行中のため見送り」になる
- 毎回の順番
  1. 競走馬登録・抹消一覧(1日1回。登録は毎週月曜、抹消は月・木に出る) → [登録.tsv](登録.tsv)・[抹消.tsv](抹消.tsv)。抹消された馬はページを取り直して抹消日を入れる
  2. この45日に終わった開催の全レースの結果 → 走った馬のページを取り直す(成績・賞金・馬体重が増えるので)。JRAの馬ページはレースから数日おくれて成績が入る(通常、月曜と木曜に更新)ので、14日以内に走った馬はそのレースが入るまで1日1回取り直す(state/ran_recent.tsv)
  3. 出馬表(1日1回) → まだDBにいない馬(新馬など)のページ
  4. 馬のページ → 父・母・母の父・母の母のページと、母・母の母の「産駒一覧」も取る(産駒一覧は60日ごとに取り直す)
  5. 取る予定の馬が600頭より少なくなったら、過去の開催を1日・1場ずつ遡る(新しい月から1986年1月まで。JRAに馬のページがあるのは現役馬と1986年以降の抹消馬)
- 1回で取れるのはおよそ5,000頭(1分に約110頭)。最初は遡りが終わるまで数週間かかる(進み具合は 概要.md の「遡り」)
- 取ったものはすぐ `state/journal_*.tsv` に足すので、途中で止まっても次の実行で続きから入る
- JRAには1度に3本・0.5秒おきに取りにいく(run.sh と同じ)。JBIS は10分に1回までなので使わない

## 使い方
- 馬名で引く: `perl 自動実行/馬DB/find.pl <馬名> [近走の数]`(競走馬・種牡馬・繁殖牝馬のどれでも。同じ名前が無ければ名前の一部で探す)
- 重賞の判断材料・出走馬ファイルを作るときに、各馬の母の産駒(きょうだいの成績・距離・芝ダ)、父の芝ダ・距離・道悪の成績を見る
- 種牡馬の数字は、DBに入った産駒のぶんだけ。遡りが進むまでは古い産駒が抜けている(概要.md の頭数で確かめる)

## JRA-VAN で補った全部入り版(PCだけ。2026-10-29〜)
- JRA-VAN Data Lab の全データ(競走馬マスタ・繁殖馬マスタ・産駒マスタ・1986年からのレース結果)から、[jv.pl](../../自動実行/馬DB/jv.pl) が `馬情報/JRA-VAN/馬DB/` に作る。JRA-VAN のデータは再配布できないので、GitHub に送る このフォルダーには混ぜない(クラウドのルーティンからは見えない)
- 中身: 競走馬/・出走履歴/(JRA-VAN の全馬。列はこのフォルダーと同じ。馬名意味・取引市場・レーティング・地方/海外賞金・Rt は無い)、繁殖馬.tsv(国内外の種牡馬・繁殖牝馬の全部。産駒数は地方の馬も入れた国内の血統登録の数)、種牡馬.tsv・繁殖牝馬.tsv・概要.md(このフォルダーの馬を先に使い、いない馬を JRA-VAN から補って数えたもの)
- PCタスクが毎回 JRA-VAN の update.sh のあとに作り直す。`update.pl` も実行のたびに全部入りのまとめを作り直す。find.pl は全部入り版があればそちらも引く

## まだ入っていないもの
- 地方競馬だけで走った馬・海外の馬(JRAにページが無い)。父・母が外国の馬のときは名前だけ入る
- 種牡馬の繋養先・種付料はアロースタッドの一覧にある馬だけ。セリの価格は「取引市場」の欄だけ
- 走っていない現役馬の転厩・馬主の変更は、次に走るか抹消されるまで取り直さない
