# 先読み競馬チャンネルの動画まとめと検証

- 出典: YouTube「先読み競馬チャンネル」(https://www.youtube.com/@sakiyomikeiba)。2026-10-23に全200本(通常動画のみ。ショート・ライブなし、メンバー限定なし)の字幕を取得
- 本人の立場: 「期待値(予想勝率×オッズ)が100%を超える馬だけ買う」「穴馬専門」。重賞ごとに過去5〜10年の「馬券直結データ」(好走条件)を3つほど出して、当てはまる穴馬を推す形が大半(約180本)
- 数値は動画内の説明で未検証。下の「検証」は 2026年4〜10月の平場(馬情報/過去レースデータ/、1,871レース)で、勝率÷市場の勝率(1/オッズを正規化)を前半(〜7/14)・後半で比べた結果
- チャンネル登録・X・オンラインサロンの宣伝は取り込まない

## すでに入っていたもの

- 期待値=予想勝率×オッズ、何回に1回何倍を当てるかで考える、1レースの投資額は一定に → シミュレーターの期待値計算・資金管理と同じ
- 控除率は単勝・複勝20%、馬連・ワイド22.5%、馬単・3連複25%、3連単27.5% → 馬券の買い方の資料と同じ
- 1番人気の3着以内率は約64%なので、3連複は1番人気が絡むと配当が下がりやすい → 3連複の資料と同じ
- 「本命の単勝1点+本命と1番人気の馬連1点」(1番人気が強いレースで、1番人気に勝てそうな馬を本命にする) → simulator の synthHint・axisHint(馬連1点向き)と同じ考え。機械的に「1倍台の1番人気がいるとき2〜5番人気の単勝」は既に検証済みで逆(2番人気1.00・3番人気0.72)
- 中山は直線が短く急坂で前有利、外回りでも直線は同じ310m / 新潟は内回りが前有利・外回りは差しも届く・千直は外枠 / 札幌は円に近くまくりが決まる・函館は楕円で坂があり前有利 → 競馬場の特徴_JRA10場.md・COURSE_PRESET と同じ向き
- 当日の馬体重が大きく動いた馬・太め残り → race_json.pl の馬体重の増減の補正
- 秋の中山開幕週は芝が最も良く、時計が速く前が止まりにくい → 当日バイアス(bias.pl)で扱う

## 検証して不採用にしたもの

| 動画の主張 | 検証結果 |
|---|---|
| 昇級馬(前走1着で上のクラス)は「どう評価していいか分からない」で人気にならない | 1〜3番人気1.00倍・7番人気以下1.03倍で市場どおり。4〜6番人気は0.82(前半1.15・後半0.49)でぶれる |
| 地方から戻った馬は「地方帰り」というだけで嫌われる。中央で好走していた馬が狙い目 | 中央で3着以内がある地方戻りは0.78倍で逆。3着以内がない馬は1.57倍だが3着以内率5.7%・勝ち6頭の大穴頼み(194頭)で採らない |
| 非根幹距離(1800・2200m など400mで割り切れない距離)が得意な馬がいる | 芝の「非根幹で好走・根幹2戦以上で好走なし」が非根幹に出ると1.22倍だが、「根幹1戦で好走なし」は0.78倍、根幹に出たときの差もなし(1.03)。区切り方で逆になるので採らない(菊花賞・宝塚記念など重賞の手で見る目安にだけ使う) |
| 前走で上がり最速なのに負けた馬 | 1.10倍(前半0.92・後半1.28)でぶれる |
| 東京・新潟外回りの瞬発力勝負で負けた馬が中山(急坂・小回り)で巻き返す | 前走4〜9着は1.00倍で市場どおり、10着以下は0.78倍 |
| 前有利の競馬場(中山・函館など)で差して届かなかった馬が、東京・新潟の長い直線で届く | 0.76倍(94頭)で逆 |
| 函館で中団から届かなかった馬が札幌で巻き返す | 0.27倍(153頭で1勝)で逆 |
| 大型馬(470・500kg以上)が有利(スプリンターズS・金鯱賞など多数) | 新馬以外の平場で芝500kg以上0.96倍、ダート1.02倍、1400m以下の500kg以上1.04倍で市場どおり。既存の「500kg以上 +1・420kg未満 -2」のまま |
| 6歳以上は割り引き、4・5歳が有利(天皇賞秋・JCなど) | 平場のオープンは6歳0.80・7歳以上0.54倍だが、3勝クラスの7歳以上は1.48倍で逆、2026年の重賞では1〜3番人気の7歳以上の3着以内率56%(4〜5歳43%)。全体の補正にはしない(天皇賞秋は判断材料の「5歳以下」で手で見る) |
| ルメール騎手が午前中に勝つと、午後の騎乗馬が売れすぎる | 平場データに騎手名と時刻がないため検証できない。期待値計算で過剰人気は扱われる |

- 天皇賞秋: 5歳以下 / 同じ年の安田記念に出て、1800m以上のG2以上で連対したことがある馬 / 左回りのG1で好走歴 → [2026-11-01_天皇賞秋_判断材料.md](2026-11-01_天皇賞秋_判断材料.md)
- 阪神JF(12月): 関東馬(前哨戦が関東の牝馬限定戦に多く、長距離輸送が1回で済む)・460kg以上・上がり2位以内。アルテミスS組は大型の一流馬以外は苦戦 → [2026-10-24_アルテミスS_判断材料.md](2026-10-24_アルテミスS_判断材料.md)

## 手で見る目安(自動計算には入れない)

- 前走で大敗していても、敗因がはっきりしている(不利・出遅れ・向かない展開・合わない馬場)なら着順で割り引かない。関係者コメントの「前走は〇〇が痛かった」を見る
- 昇級馬は「前走が恵まれて勝ったか(超スローの逃げ切り・開幕週の内枠で楽をした)」を見る。恵まれずに勝った馬だけ上のクラスでも買う
- 中山は坂を2回上るコース(芝1800・2000・2200・3600m、ダート1800・2400m)ほどスタミナが要る
- 新潟は開催中にコース替わりがないので、開催後半ほど外差しが決まりやすい
- 馬体重で走りが変わる馬がいる(「503kg以下なら買い」のように、その馬の体重別の成績を見る)
