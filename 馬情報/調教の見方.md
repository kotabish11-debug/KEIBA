# 調教(追い切り)の見方

出典: YouTube「上昇」の調教の見方の動画(ユーザー提供の文字起こし、2026-10-21)を要約。LINE・予想AIの宣伝部分は除く。数値は動画内の説明で未検証。
関連: [予想で捨てる情報.md](予想で捨てる情報.md)(調教タイムの単発の時計は使わない)、[馬の走り方と調教.md](馬の走り方と調教.md)(坂路・美浦の改修)

## 前提
- 調教は「能力を**発揮できる状態か**」を読む材料(予想の2本柱「能力があるか」「それを発揮できるか」の後者)
- 「追い切り絶好調」「好時計」は全員が見ているので、もうオッズに入っている。時計の速さだけで買うと、人気になっただけの期待値のない馬をつかむ
- 調教の時計はコース・その日の馬場・追った強さでいくらでも変わる。**同じレースの馬どうしで時計を比べる(横の比較)のはほぼ意味がない**

## コースの違い
- 坂路: 坂を登るので負荷が大きい
- ウッドチップ(W): 脚への負担が少なく、しっかり負荷をかけられる。主力のコース
- ポリトラック(P): **時計が速く出やすい**。Pの好時計だけで飛びつかない

## 縦の比較(その馬自身の過去と比べる)
- 過去に好走したときと同じくらいの時計・同じ内容で仕上がっていれば、状態は良さそう。明らかに地味・軽ければ疑う
- 人気馬ほどここを見る。履歴は JRA や競馬新聞(競馬ラボ・netkeiba)の調教欄で確認

### 見るのは「本数」と「質」
- **本数**: 前走から今回までに何本追ったか。陣営の本気度が分かる。例: 半年ぶりの前回は4本で3着、今回の休み明けは2本 → 前回ほど仕上がっていない(叩き台)のでは。**それが人気馬なら嫌うチャンス**(そこまで見ている人は少ない)
- **質(強さ)**: 馬なり(無理に追わない)か、一杯(しっかり追う)か。同じ時計なら馬なりの方が余裕がある
- 本数が少なく、内容が全部馬なり → 本気の仕上げではなく、次を見据えているのでは

### 速い時計の落とし穴
- 全力で走ると筋肉の回復に3〜4日かかる。水曜追い切り→日曜レースは中3日なので、**当週に強く追いすぎると疲れが残る**ことがある
- 近年は1〜2週前に長めを強めに追い、当週は軽く整える厩舎が増えた。**1週前にしっかり負荷をかけていれば、当週が軽いのは計算どおり**(当週の時計が地味でも減点しない)。その馬・その厩舎のいつものパターンと比べる

### いつもと違う調教には理由がある
- いつもウッドで乗り込む馬が急に坂路中心になった → ウッドを使えない事情(脚元・体調)を疑う
- 例: バトルボーン(4連勝でオープン入り)は、もとは美浦のウッド中心。右前の骨折など故障が続き、復帰後は脚元に配慮して坂路中心に変わった → 万全ではないと読める(2026年7月12日の七夕賞は4番人気12着)。ウッド中心に戻ってきたら注目
- 逆に、近走が今ひとつでも本数が増えて動きが上向いていれば、状態が上がってきていると前向きに見る
- 坂路だから悪い、ではない。**過去からどう変わったか、その裏の事情**を読む

## 初心者がつまずく点
- 調教の映像は無理に見なくていい(プロでも難しい)。縦の比較・本数と質・パターンの変化は数字と文字情報だけで判断できる
- 新聞の調教評価・コメント(トラックマン)はその人の予想。参考にとどめ、自分で判断する

## シミュレーターへの反映(2026-10-21)
- 全レースの自動計算(race_json.pl)には入れない。調教の履歴(本数・コース・強さ)を自動で取っていないため
- 手で付ける基準([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md) の「調教」)を具体的にした。どれも今までどおり `choshi` ±2 の範囲(新馬戦の加速ラップ +3 は別):
  - -2: 休み明けで、前回の休み明け好走時より本数がはっきり少ない / 本数が少なく全部馬なり / いつものコース(ウッドなど)から急に坂路中心に変わり、故障明けなど理由が考えられる
  - +2: 近走は不振でも本数が増えて強めの内容が続く / 故障明けで坂路中心だった馬がいつものコースに戻した
  - 動かさない: 他の馬との時計の比べ合い / ポリトラックの好時計 / 1週前に強めで当週が軽い(その厩舎のいつものパターンなら)
- 情報収集の手順([情報収集の手順.md](../情報収集の手順.md) の4)で、重賞の人気上位の馬は追い切りが出たら上の基準で確かめるようにした
