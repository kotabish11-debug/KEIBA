# 馬券の買い方: 3連単とNGな買い方

出典: YouTube「コタ」(指数表・当日予想を配信)の「99%が経験あり、絶対にやめるべきNGな馬券の買い方2選」(ユーザー提供の文字起こし、2026-10-22)を要約。公式LINE・番組の宣伝部分は除く。数値・配当は動画内の説明で未検証。馬名は文字起こしからの推定を含む。
関連: [馬券の買い方_3連複.md](馬券の買い方_3連複.md)・[馬券の買い方_単勝・馬連・馬単.md](馬券の買い方_単勝・馬連・馬単.md)・[軸馬と相手の選び方.md](軸馬と相手の選び方.md)

## NG1: 3連単のマルチ・ボックス
- マルチは軸と相手の着順を入れ替えた組も同時に買う。点数は1着固定と比べて1頭軸で3倍、2頭軸で6倍(3連複の2頭軸と比べても6倍)
- 点数が6倍なら配当も3連複の6倍ないと釣り合わないが、実際は届かないことが多い
  - 例(2026年高松宮記念): ◎サトノレーヴ1着・▲レッドモンレーヴ(15番人気)2着・無印ウインカーネリアン3着。◎-○▲の2頭軸で相手8頭なら3連複14点・3連単2頭軸マルチ78点。3連複5万610円に対して3連単24万5730円で、6倍(約30万円)に届かない → 3連複を1点600円で買う方が得
  - 人気薄が◎を負かして1着なら3連単が上回るが、G1で単勝100倍以上の馬が勝ったのは2011〜2026年の約400レースで3頭だけ(2016年以降は1頭)。狙って当てるものではない
- 払戻率も3連複75%・3連単72.5%で、同じお金を同じ組に使うなら3連単は2.5%不利
- 3連単を買うなら **◎を1着に固定したフォーメーション**(高松宮記念の例では78点→26点)。3連単は単勝の延長で、①単勝で買える◎を探す → ②2列目に危険な人気を除いた実力上位を置く馬単 → ③3連単 の順に身につける
- 「荒れると思うレースはマルチの方が効率的」は矛盾。荒れると思うなら人気馬こそ1着から外すべき
- **基本は馬連・3連複、3連単は◎が1着のときのボーナス**。◎が2・3着でも当たりが残り、1着なら全部当たる。2・3列目に買いたい馬がいなければ、無理に馬単・3連単を買うより単勝
- ボックスはさらに点数が増え(9頭で504点、6頭でも120点)、軸の考えがなく再現性もないので買わない

## NG2: 人気馬だけの組み合わせ
- 控除率が平均25%あるので、多くの人と同じ人気の組を買い続けると長期では必ず負ける。対抗策は期待値の高い穴馬を買い目に入れること
  - 例(2026年安田記念): ◎ガイアフォース(1番人気)から、期待値の高い8番人気シックスペンス・9番人気ウォーターリヒト・12番人気の3頭へ馬連3点。シックスペンス1着・ガイアフォース2着(同着)で24.3倍。2〜5番人気を2列目に入れていたら、そこに資金を取られて払戻が減っていた。ガイアフォースは2着タイプで単勝は期待値が低いと見て単勝系は買わなかった
- 人気馬を軸にするのはよいが、**相手は中穴〜大穴**にする。人気同士で決まると思うレースは見送る
- 2026年のG1は「1〜5番人気2頭+6番人気以下1頭」の3着以内が多かった(大阪杯1-5-12番人気、皐月賞1-4-9、天皇賞春1-12-2、ダービー1-4-11)。この形なら3連複で1〜3番人気の一番信頼できる馬を軸、2列目に1〜5番人気の次の2頭、3列目に手広く穴(選ばなかった人気馬は消す)
- まずは今買っている馬券から、人気馬だけで決まる組を全部削るだけでも収支は良くなる

## シミュレーターとの関係
- もともと期待値で1点ずつ組を選んでいるので、マルチ・ボックスの形で買うことはなく、人気馬だけの低配当の組も期待値が足りなければ自然に外れる(二重に補正しない)
- 1番人気軸で2列目を穴だけにする形は `favHoleHint`(「1番人気軸の穴流し」)で表示済み
- **追加したこと(simulator.html の `pickBets`)**: 3連単は ◎(シミュレーションの勝率1位)が1着の組だけを候補にする。期待値が足りていても、◎以外が1着の3連単は買い目に入れない。券種の説明欄にも追記
- 3列目の手広い穴流しは、人気薄が売れすぎやすいので引き続き不採用([馬券の買い方_3連複.md](馬券の買い方_3連複.md))
- 少頭数の3連単ボックス例(`smallFieldHint`、[少頭数レースの狙い方.md](少頭数レースの狙い方.md))は、10頭未満・人気馬を消せるときだけの3頭6点の例示なので残す

## 追記: 3連単のフォーメーションの組み方(コタ「本当は教えたくない効果的な3連単の買い方」、2026-10-22)
出典: YouTube「コタ」の文字起こし(ユーザー提供)。SNS・チャンネル登録の宣伝部分は除く。配当・点数は動画内の説明で未検証。馬名は文字起こしからの推定を含む。

- 3連単の売上は全券種の約3割(令和3年29%、3連複と合わせて約5割)。攻略できれば効果が大きく、間違えると大きく負ける券種
- 買い方は フォーメーション・マルチ・ボックス(と通常)。**ボックスは使わない**: 1〜3番人気だけの組(多くの人が買う低配当)と、まず来ない大穴だけの組を自動で買わされ、消したい組を消せない(例: 2025年有馬記念で印の11頭ボックスは990点)
- **マルチも使わない**: 2頭軸マルチ30点は3連複なら5点。3連単が3連複の6倍以上つくレースはほとんどなく、払戻率の差2.5%分も損(例: 2014年CBC賞は3連単11万6100円×200円=23万2200円、同じ6000円を3連複5点に1200円ずつなら2万2400円×12=26万8800円)。馬単マルチと馬連も同じ関係
- 頭に穴が来そうなら、人気馬を1着にしたマルチではなく、**人気馬を2・3着に固定して1着に6〜10番人気を数頭**置く。勝ち切れない強い馬(例: ダノンデサイル)も2・3着固定で使える
- **狙い**: 50〜100点で5万〜20万円の中穴を狙う。**危険な人気馬は1頭必ず消す**。高配当が出そうなレースだけ選び、1番人気を軽視できるレースで高配当だけを狙う
- **組み方**(2025年秋華賞、◎エンブロイダリー・1番人気カムニャを消して3連単12万9850円):
  1. ◎1着固定 → 2列目に ○▲△ → 3列目に 消した馬以外の全頭(28点)
  2. 2列目と3列目を裏返す(◎1着 → 3列目の全頭 → ○▲△)で28点、計56点が基本
  3. ◎が1着でないと当たらないのがつらければ、◎を2着にした同じ形を足して112点まで(1着を1〜2頭増やすマルチより点数の割に配当が大きい)。人気の最下位を削って減らすより、大穴の3着を拾える方を優先
  - 3連単はあくまで単勝の延長。◎が1〜3着のどこでも当たる形(ボックス・マルチ)にすると点数と期待値の低い組が増える
- **低配当の組を消す**: 断然人気を◎にすると、組によっては80〜100倍程度の低配当が出る。**200倍(2万円)未満の組はどのレースでもほぼ消す**。2025年マイルCS(◎ジャンタルマンタル、2・3番人気を消す)は54点・合成オッズ7倍 → 200倍未満を外して45点・14倍。結果は15番人気が3着で3連単5万2470円
  - 合成オッズ = どの組が当たっても同じ額が戻るように配分したときの倍率(例: 2倍に1万円・10倍に2000円ならどちらでも2万円)
  - 2025年有馬記念を同じルールで組むと64点 → 200倍未満を外して52点・合成オッズ15.85倍
- 資金が少なければ3連複も選択肢。フォーメーションは3連単の1/6には絞れないが、2025年マイルCSは3連単5万円台に対して3連複2万3090円と、点数の割に3連複の方が割安なレースも多い

### 2026年重賞での確認(馬情報/2026重賞結果 の119レース)
- 3連単の配当: 2万円未満 41レース(34%)・2〜5万円 22(18%)・5〜20万円 29(24%)・20万円以上 27(23%)
- 動画が狙う5〜20万円の帯は約4レースに1回。2万円未満の決着も3分の1あるので、200倍未満を消すと3回に1回ほどは「当たり方が低配当なら取れない」ことを受け入れる買い方になる

### シミュレーターに入れたこと・入れなかったこと
- **入れた**: 買い目欄の合成オッズ(`synthHint`)に3連複・3連単を追加し、3連単は「200倍未満の◯点を外すと◯倍」も表示。外すかどうかはユーザーが判断する
- **入れなかった**: 3連単の200倍未満を買い目から自動で外すこと。シミュレーターは組ごとの期待値で選んでおり、低配当の組は期待値が足りなければ自然に外れる(人気馬だけの組と同じで二重に補正しない)。一般に人気の組ほど回収率は下がりにくいとも言われ、一律に外すと期待値の高い組まで消える
- **入れなかった**: ◎2着の形(112点)と3列目の全頭流し。シミュレーターの3連単は◎1着だけ(上のNG1)で、3列目の手広い穴流しは人気薄が売れすぎやすいので引き続き不採用([馬券の買い方_3連複.md](馬券の買い方_3連複.md))
- 危険な人気馬を1頭消す・荒れるレースを選ぶ・人気馬の2・3着固定は、`favRisks`・`g1Hint`・`axisHint`(券種別の軸)・`favHoleHint` で表示済み
