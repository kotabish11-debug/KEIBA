# 飯野先生@競馬予想攻略の動画まとめと検証

- 出典: YouTube「飯野先生@競馬予想攻略」(https://www.youtube.com/@iino_keiba_coach)。2026-10-23に一覧を取得: 通常動画97本・ライブ448本(全頭解説・WIN5回顧・重賞攻略法)・ショート4,688本。**メンバー限定の動画は見られないので対象外**(通常動画の約2割、ライブの大半)
- 本人の立場: 単勝1点が基本、1〜5番人気(勝率の合計が約80%)から「危険な1番人気」を消して残りの単勝を買う。的中率20〜25%・単勝4〜5倍が目安
- 数値は動画内の説明で未検証。下の「検証」は 2026年4〜10月の平場(馬情報/過去レースデータ/、約1,800レース)で、勝率÷市場の勝率(1/オッズを正規化)を前半(〜7/14)・後半で比べた結果
- 個別指導・LINE登録・メンバーシップの宣伝、メンタル・心構えの話は取り込まない

## すでに入っていたもの

- 前走2着の馬は人気しすぎ(単勝回収率約70%) → race_json.pl の choshi -2(2〜3番人気の前走2着は市場の0.73〜0.76倍で裏付けも同じ)
- 前走0.5秒以上の大差勝ちは人気しすぎ → favRisks の「前走の圧勝」(検証: 前走1着0.4秒以上差の1〜3番人気は0.88倍)
- 単勝1倍台は勝率約50%、1番人気が4倍以上の混戦は勝率約16% → オッズそのもので期待値計算済み
- 道悪で好走した次の良馬場の人気馬 → race_json.pl「前走は道悪で好走・今回は良」-3
- 騎手(ルメールの芝2400m以上・重賞8枠、川田の先行と2500m以上が苦手、戸崎の外枠と重賞の1番人気18.5%、坂井の先行・内枠・ダート重賞・500kg以上、松山の外枠の差しが苦手、岩田望来の阪神京都と東京の苦手、西村淳也の関東ダートの苦手) → 騎手の得意・苦手.md と simulator の JOCKEY_TIPS に同じ内容が入っている(以前取り込んだ「7人の癖」と同じ)
- 単勝は1〜5番人気・4〜5倍を中心に → 単勝の帯(4〜9.9倍、10倍以上は買わない)と同じ考え
- 競馬場ごとの勝ちパターン(京都芝1200は4角5番手以内、京都外回りは中団から上がり上位、阪神内回りは内枠の先行、中山芝1800は4角5番手以内、東京芝2000は14頭以上の7・8枠が不利、東京ダートは外枠、など) → 競馬場の特徴_JRA10場.md・COURSE_PRESET・ダートの枠の初期値と同じ向き

## ライブ・ショートについて
- 取得できたのはライブ94本(残りはメンバー限定)・ショート1,894本(残りは字幕なし・メンバー限定)。ライブは全頭解説・WIN5回顧・メンタルの話が中心、ショートは通常動画の切り抜きで、新しい一般的な主張はほぼなかった
- 新しかったのは「京都の長距離(菊花賞など)は、坂の下りに慣れた関西の騎手を人気の関東の騎手より優先」だけ。騎手名が学習データにないため検証できず、重賞で手で見る目安にとどめる(ルメールは別格の扱いのまま)

## 手で見る目安(自動計算には入れない)

- 単勝の作戦: 「単勝4倍以上を的中率25%」か「5倍以上を20%」のどちらかに決める。1倍台の1番人気が勝ちそうなレースは見送る(G1は別)。2頭で迷うレースは見送る
- ルメールへの乗り替わりで2・3番人気に留まる馬は妙味がある(1番人気にならないとき)
- G2・G3では G1で好走した実績馬、3勝クラス〜リステッドでは「2走以内に重賞で3番人気以内」だった馬が力上位
- 2勝クラスで2・3着を繰り返す「頭打ち」の馬は人気でも単勝は買わない
- ハンデ戦のトップハンデ、夏の小回りでの人気の差し馬は割り引く
