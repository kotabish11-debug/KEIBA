## ダート
ダートは良馬場より馬場が悪い方が時計が出やすく、多くの種牡馬で道悪での差は小さい。

|---|---|---|
| ナダル | **さらに上がる**(良でも勝率15%) | 新しい種牡馬 |
| パイロ | **悪くなるほど上がる**(重・不良で勝率14.1%) | |
| サンダースノー | **下がる** | ほかの上位はアメリカ系、この馬はアイルランド産 |
| ロードカナロア | 稍重で少し悪い | 差は小さい |

## シミュレーターへの反映(2026-10-21)
- 全レースの自動計算(race_json.pl): 出馬表から父を読み、**道悪(稍重以上)の経験が2戦以下の馬**だけ、`heavy`(重馬場適性)を次の種牡馬で ±1 する。経験が3戦以上ある馬は、その馬自身の成績を使う
  - 芝 +1: キズナ・モーリス・イスラボニータ・ファインニードル・シスキン / 芝 -1: キタサンブラック・レイデオロ・スワーヴリチャード・コントレイル
  - ダート +1: ナダル・パイロ / ダート -1: サンダースノー
- `heavy` は馬場が悪いほど効く(良馬場では効かない)。稍重だけ得意(ドゥラメンテ・アドマイヤマーズ)や、稍重まではこなす(キタサンブラック・スワーヴリチャード・コントレイル)の区別はできないので、重・不良での傾向を優先した
- 重賞で手で付けるときも、道悪の経験が少ない馬はこの表で `heavy` を ±1 する([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md))
