## 2. 競馬AI開発～入門編～（Zenn本、著者 aiss）
- URL: https://zenn.dev/ss_learning/books/442f0089d2b88a
- **有料の本のため本文は取得できず**（目次のみ確認）
- 目次から分かる開発の流れ:
  1. 競馬AI開発の概論
  2. データの準備（TARGET / JRA-VANのデータを使う前提）
  3. エクセルで簡単な指数を作る（練習）
  4. Pythonとライブラリでデータ分析
  5. データの選定・加工 → 特徴量の作成
  6. 機械学習モデリング
  7. 実運用（業務効率化、TARGETデータを使った運用システム）
- このシミュレーターでも「データ集め → 指数 → 特徴量 → モデル → 買い目」の順で育てるのが良さそう

## 3. 競馬ラボ 競馬データベース
- URL: https://www.keibalab.jp/db/
- WebFetch では 403。curl にブラウザの User-Agent を付ければ取れる(robots.txt で /db/ は禁止されていない)
- 主なページ(ID は 年4桁+月日4桁+場コード2桁+R2桁。例 202610180811 = 2026/10/18 京都11R 秋華賞)

| ページ | URL | 中身 |
|---|---|---|
| 出馬表 | `/db/race/<ID>/` | 出走馬・騎手・調教師・父母 |
| 馬柱 | `/db/race/<ID>/umabashira.html` | 近走成績、**馬番×コース・種牡馬×コースの連対率**、**このコースで有利な枠・脚質**、得意な騎手・調教師・種牡馬 |
| 過去レース | `/db/race/<ID>/past.html` | 過去の同レースの結果・上がり・通過順 |
| レース傾向 | `/db/race/<ID>/trend.html` | その日の脚質・人気別の1〜3着 |
| 血統 | `/db/race/<ID>/blood.html` | 血統分析 |
| 馬・騎手・調教師 | `/db/horse/<ID>/`、`/db/jockey/<ID>/`、`/db/trainer/<ID>/` | 個別の成績 |
| リーディング | `/db/leading.html?kind=jockey`(trainer/owner/breeder) | 順位表 |
| 重賞一覧・傾向 | `/db/race/grade.html`、`/db/race/trend.html` | |

- 「騎手×コース連対率」はログインしないと0%表示だった(会員限定の可能性)
- 例: 2026秋華賞(京都芝2000m)の馬柱では、このコースで有利な脚質=逃げ、得意な騎手=武豊・ルメール・岩田望来、得意な種牡馬=ジャスタウェイ・キズナ・キタサンブラック

## 4. netkeiba オーナーズ 種牡馬リーディング
- URL: https://own.netkeiba.com/sire/stallion_leading.html (`?type=1` 中央、`?type=2` 地方)。年は1956年から選べる
- curl(ブラウザの User-Agent)で取れる。1ページで上位50頭
- 2026年分の上位50頭を保存した(2026-10-16取得): [種牡馬リーディング_2026_中央.csv](種牡馬リーディング_2026_中央.csv)、[種牡馬リーディング_2026_地方.csv](種牡馬リーディング_2026_地方.csv)
  - 列: 出走・勝利数(重賞/特別/平場/芝/ダ別)、勝馬率、EI、賞金、平均勝ち距離(芝/ダ)、代表馬。最後の2列「芝勝率・ダ勝率」は勝利回数÷出走回数で自分で計算した
  - 使い方: 出走馬の「父」で引いて、芝・ダート向きか、得意な距離(平均距離)を見る
- 種牡馬ごとの産駒成績: `https://own.netkeiba.com/db/sire_crop_result.html?id=<ID>`

## 5. JBISサーチ(日本軽種馬協会)
- URL: https://www.jbis.or.jp/
- 血統・生産牧場・せり・ランキングのデータベース。馬名・騎手名・調教師名で検索できる
- **robots.txt で Crawl-delay 600(10分に1回まで)**、/premium/・/csv/ は禁止 → 自動収集・定期実行には使わない。必要なときに手で1〜2ページ見る程度にする
- 利用規約: 個人的な利用はOK。商業目的の複製・転売は禁止
- 主なページ: 馬 `/horse/<ID>/`、レース結果 `/race/result/<日付>/<場コード>/<R>/`、ランキング `/ranking/`

## 6. アロースタッド 種牡馬一覧
- URL: https://www.arrowstud.jp/stallion.html (北海道の種牡馬牧場。robots.txt は全部許可)
- 2026年に繋養している32頭の血統(父・母・母父)と種付料を保存した: [種牡馬一覧_アロースタッド_2026.csv](種牡馬一覧_アロースタッド_2026.csv)
- 新種牡馬7頭: イグナイター、ウシュバテソーロ、ジャスティン、ジャスティンパレス、トウシンマカオ、ペプチドナイル、ミスティックロア(産駒デビューは2029年頃)
- 種付料が高い(＝生産者の評価が高い)順: シニスターミニスター 800万、モズアスコット 600万、ウシュバテソーロ 300万、テーオーケインズ 250万、カフェファラオ・パンサラッサ 200万
- ダート系の種牡馬が多い(シニスターミニスター、カフェファラオ、テーオーケインズ、ヘニーヒューズ系など)→ 地方・ダート戦で父を見るときの参考

- 「2020年 配合種牡馬別 生産予定馬一覧」をCSVにした: [社台ファーム_2020年配合一覧.csv](社台ファーム_2020年配合一覧.csv)(454件、種牡馬72頭)

## 21. 競馬ブック スマートフォン版
- URL: https://s.keibabook.co.jp/ (競馬専門紙「競馬ブック」のスマホ向けサイト)
- 2026-10-18 に追加(ユーザーの依頼)。**このクラウド環境からは接続拒否(プロキシ 403)で中身は未確認**。ネットワーク設定の許可ドメインに `s.keibabook.co.jp` を足すと取得できる
