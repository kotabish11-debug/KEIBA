# 注目馬メモ

レースの振り返りで「着順以上に強い競馬をした馬」を書いておき、次に出走したときに評価に使う(手順は [情報収集の手順.md](../情報収集の手順.md) の「3-2. 予想の振り返り」)。
考え方の出典: YouTube「上昇」の1週間のルーティンの動画(ユーザー提供の文字起こし、2026-10-21)。

- 書く馬: 不利があった / トラックバイアスに逆らって好走した / 展開(ペース)が向かなかったのに差が小さかった
- 次走で使うときも、枠順と今回のメンバーとの力関係で最終判断する(メモがあるから必ず買う、ではない)
- 次走を走り終えたら「済」に移す
