# 馬券の買い方: 大穴を軸にした3連複(一見堅いレースの逆張り)

出典: YouTube「コタ」の「完全講義 3連複50万馬券の狙い方」(ユーザー提供の文字起こし、2026-10-22)を要約。数値は動画内の説明で、自分で検証したものではない。宣伝(指数表・LINE・有料プラン)の部分は省いた。

## 考え方
- 3連複50万円以上は年10回程度(2026年上半期は4回)しか出ない。狙うのは「毎週当てる」ためではなく、たまに大きく当てて年間の収支を押し上げるため
- 50万級を取れる買い方ができれば、3連複10万円級はもっと取りやすくなる
- 1レースに大きな金額は要らない。少額で続け、当たるまで待つ

## 1. 一見堅いレースを逆張りする
- ハンデ戦・フルゲートのような「誰が見ても荒れそうなレース」は、各馬の支持が割れているので、人気馬が崩れても3連複は数万円止まり。50万級にはほぼならない(重賞で3連複50万円以上は2022年の高松宮記念だけ)
- 狙うのは、**上位人気に票が集中していて大半の人が堅いと思っているが、実は人気馬に不安があるレース**。人気馬が売れすぎている分、人気薄には普段より大きな期待値がある
- 目安は**上位2頭の単勝の支持率の合計**。動画の例では54.1%(中京の2歳未勝利)と58.7%(新潟の未勝利)。荒れたCBC賞は36.2%しかなかった
- ただし票が集中しているだけのレースは、ほとんどが本命決着。**上位2頭の少なくとも一方を軽視できる根拠**があるときだけ参加する
  - 例: 前走は2着でも勝ち馬に1.25馬身離され、3着以下とは僅差で再現性が低い / 牝馬限定戦で2馬身以上負けている / 先行しても加速力がない・血統の割にパワー型でない・最内枠

## 2. 軸は大穴にして2・3着を狙う
- 普段の3連複は1〜3番人気の実力上位を軸にするが、50万級を狙うときは軸自体を大穴にする(動画の軸は10番人気82.4倍と11番人気50.6倍。どちらも3着・2着に入った)
- 大穴を軸にすると、人気馬の1頭が3着以内に来ても、ほとんどの組み合わせが3連複万馬券以上になる
- 大穴を選ぶ根拠(動画の例):
  - **ローテーションのレベル**: 前走がメンバーの強いレースなら、着順が悪くても見直せる。例: 夏の小倉の2歳戦は、函館・福島・小倉の3場開催で関西の素質馬が小倉に集まりやすく、そこで負けた馬が次走で好走しやすい。前走で展開が向かなかった(中団から差す馬が前残りの決着)のも見直し材料
  - 同じハイレベルなレースから来た馬が、次のレースでそろって上位に来ることが増えている(例では前走の同じレースで8・9着の2頭が2・3着)
  - **芝・ダートの替わり**: ダートから芝(新潟の例)、芝から内枠のダート替わりで良くなる血統。その日に同じ替わりの馬が好走していれば、なお狙える
  - 減量騎手で斤量が大きく減る(55kg→52kg)
- 結果: 6→13→10番人気で3連複65万円、新潟は3連複47万円・馬連1万8280円

## シミュレーターへの反映(2026-10-22)
- 予想の文章に「一見堅いレースの逆張り」を出す(`simulator.html` の `longshotHint`)。10頭以上のG1以外のレースで、上位2頭の単勝の支持率の合計が50%以上のときだけ表示する。能力値・買い目は変えない
  - 上位2頭の不安材料は G1の荒れ方(`g1Hint`)と同じ判定(`popDoubts`: 1番人気の不安材料・軸の減点-5以下・能力値からの勝率が市場の8割未満など)。どちらも不安がなければ「本命決着が多い形。逆張りはしない」と出す
  - 不安があれば、大穴の軸候補(8番人気以下・単勝20倍以上で、能力値からの3着以内率が8%以上かつ市場の1.3倍以上)を最大3頭、芝・ダートの替わりや前走の着差の材料と一緒に示す。候補がなければ「根拠のない大穴を軸にはしない」
- 全レースの自動計算(`race_json.pl`)で、前走と芝・ダートが違う馬の `note` に「ダートから芝替わり」「芝からダート替わり」を出す。動画の根拠は2レースだけなので、能力値の補正にはしない
- 重賞を手で作るときは、前走のメンバーのレベル(前走の上位馬がその後勝ち上がっているか)を見て、ハイレベルなレースで負けた馬は着順の割引を戻す(`choshi` +2まで。[レースデータの作り方.md](../シミュレーター/レースデータの作り方.md))
- 取り入れないこと
  - 大穴を軸にした3連複を自動で買い目にすること。人気薄の馬券は売れすぎやすく([馬券の買い方_3連複.md](馬券の買い方_3連複.md))、的中は年に数回なので、買い目は期待値の計算に任せ、表示は狙える形の目安にとどめる
  - 人気馬の売れすぎそのものは、期待値の計算(市場の確率との比較)ですでに扱っているので、別に補正しない
  - 夏の小倉・3場開催のような具体的なローテは、季節と開催の組み合わせが限られ、自動では判定しない
