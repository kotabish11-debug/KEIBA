# 穴馬の激走パターン

出典: YouTube「コタ」の「回収率130%のプロ直伝 本当に儲かる穴馬の激走パターン4選」(ユーザー提供の文字起こし、2026-10-22。撮影は2025年3月)を要約。LINE・note・有料プランの宣伝部分は除く。数値は動画内の説明で未検証(下の「検証」だけは手元のデータで確かめた)。

## 穴馬の考え方(前提)
- 「6番人気以下=穴」と決めつけない。1番人気が5倍台・最下位人気でも25倍の大混戦なら6〜7番人気は穴と言えず、2頭以上が馬券に来ることも普通より多い。逆に1番人気が1倍台なら、3番人気(9.5倍)でも穴の扱いでよい
- 穴馬は軸より相手・ヒモに置き、来たときに配当が跳ねる存在として使う。見つけたからといって、必ずその馬から買う必要はない。一番強い・勝つ可能性が高いと思ったときだけ単勝
- 動画内の数字: 本人の勝負レースで6番人気以下に印を打ったときの単勝回収率130%・複勝114%、勝率は6.6%(当たりが少ないので気持ちが続かない)

## 1. 中距離から短距離への距離短縮
- 前走芝1600〜2000m → 今回芝1000〜1200m の馬を狙う
- 理由: 賞金もホースマンの目標も芝の中・長距離(ダービーなど)に集まり、レベルが高い。短距離はそこへ行けなかった馬・弱い馬が多い。馬にとっても短縮の方が体もメンタルも楽
- ダートでも使えるが、ダートは陣営が血統・馬体で距離を使い分けることが多いので、芝ほど効かない

## 2. 上級条件の前崩れのレースで先行して粘った馬
- 上級条件(オープン・重賞)は力が拮抗しているので、展開ひとつで前有利・後ろ有利がはっきり出る。前が有利なのが普通なので、差し・追込が上位を独占するのは「異常事態」
- そんな前崩れの中で先行して馬券圏内に粘った馬は文句なしに評価。最後に飲み込まれて10着でも次走以降に狙える
- 前崩れの3つの原因
  - ハイペース: 前で競り合って潰れた。前後半のラップで前半が速いという数字の裏付けが必要(裏付けがなければ単に弱かっただけ)。高速馬場で数字だけ速く見えるケースもあるので、差し・追込がゴール前に一気に押し寄せていたことも確かめる → 評価する
  - 荒れた馬場: 開催が進んで内が傷み、外差しが決まる。それでも前で残った馬 → 評価する
  - スローの瞬発力勝負: 瞬発力のある差し馬が一瞬で飲み込んだだけで、先行馬は頑張っていない → 評価しない
- 崩れた先行馬が人気馬ばかりなら、そのレースは差し・追込にとても向いていた(1〜4番人気の誰も3着以内に来ないのは珍しい)。人気薄ばかりなら単に力不足

## 3. 芝からダートへのトラックチェンジ
- 芝しか走ったことがない馬の初ダートを狙う。芝のG1は年22レース、ダートのG1は2つだけで、ダートはレベルが低くなる仕組み。ロードカナロアやキズナなど芝の種牡馬がダートでも上位にいる
- 狙う条件: 前走芝・前走6着以下・ほかの出走馬は全部前走ダートで1頭だけ・前走で先行か中団の前目。2勝クラス以上で特に有効
- 買わない: 前走芝で3着以内(普通に売れる)・ダートを使っていて1回だけ芝を挟んだ馬(上積みが少ない)・前走芝の馬が4〜5頭いるレース・前走逃げた馬(通過順の「1」だけで売れる)
- 例: アイコンテーラ(BSN賞、単勝20.7倍で圧勝)、2014年KBC賞のトウシンイーグル(8番人気で圧勝)

## 4. 東京で惨敗して中山に出る馬
- 東京と中山は同じ関東でも求められる適性が逆。東京=切れる脚・スピード・ギアチェンジ(王道の強い馬)。中山=器用な立ち回り・長く使える脚・スタミナ。中山は穴馬の前残りや後方一気も多く、人気馬は前が壁になって終わることがある
- 中山の芝は主要4場で一番重く、小回りという点もローカルと同じ。ローカル(福島・北海道)で好走した馬の方が、東京・阪神で走った馬より適性で信頼できる
- ダートはさらに極端で、中山は中央で一番時計がかかるダート、東京は一番時計が出るダート
- 年末の5回東京のダートで好走した馬は、直線だけの競馬・芝寄りのスピードの馬ばかりなので、12月の中山ダートで人気になってもよく飛ぶ
- 逆の応用: 短距離で好走してマイルで人気になる馬は危ない

- 3は手元のデータでは裏付けがない(上級条件では61頭で1勝もなし)。条件を全部満たす馬は43頭しかいない。前走逃げの馬が売れすぎる点だけは動画どおり
- データは平場だけで、重賞・リステッドは入っていない。動画の主張の中心(オープン・重賞)は確かめられていない

## シミュレーターへの反映(2026-10-22)
- 全レース自動計算(race_json.pl、`choshi`。ほかの補正と合わせて±5まで。理由は `note` に出る)
  - 2勝クラス以上・同じ馬場・前走ハイペース(馬柱のH)・前走1角と4角とも3番手以内・4〜10着 → **+2**「前走ハイペースを先行して粘った」
  - 今回中山・前走東京(同じ馬場)で3着以内 → **-2**「前走は東京で好走・今回は中山(適性が逆)」
  - 今回中山ダート・前走東京ダートで6着以下 → **+1**「前走は東京ダートで凡走・今回は中山ダート」
- 入れない: 1(既存の短縮ルールで足りる・回収率が低い)、3(データで裏付けなし。トラック替わりは `note` に出るだけのまま。外枠の先行馬の +2 は[大外枠が激走する条件.md](大外枠が激走する条件.md)で別に検証済み)、短距離→マイルの人気馬(差がない。延長は軸の減点に入っている)
- 穴馬の扱い(相手・ヒモに置く、混戦なら穴の基準を上げる)は買い目の期待値計算で扱えているので変えない
- 重賞を手で作るときの基準は [レースデータの作り方.md](../シミュレーター/レースデータの作り方.md)。関連: [展開予想の手順.md](展開予想の手順.md)・[競馬場の特徴_JRA10場.md](競馬場の特徴_JRA10場.md)・[短距離戦の見方.md](短距離戦の見方.md)
