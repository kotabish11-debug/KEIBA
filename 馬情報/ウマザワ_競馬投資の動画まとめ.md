# ウマザワ【プロ競馬投資家】の動画まとめと検証

- 出典: YouTube「ウマザワ【プロ競馬投資家】」(https://www.youtube.com/@ウマザワ)の全20本(2026-10-23に自動字幕を取得。ショート・ライブはなし)
- 動画内の数値は本人の説明で未検証。下の「検証」は 2026年4〜10月の平場(馬情報/過去レースデータ/、新馬・障害を除く約22,500頭)と払戻 1,542レースで確かめた結果。「前半」は7月14日まで、「後半」は7月15日から
- メルマガ・特典・AI予想ツールの宣伝、精神論(投資の心構え・感情を消す・ルールを守る)の部分は取り込まない
- 全体の印象: 言い回し・例え(「資金×0.08÷オッズ」「1000円が2600円になって最後に外す」など)が [バフェット](バフェット_競馬投資の動画まとめ.md) とほぼ同じ台本で、主張の多くはそちらで検証済み。新しい具体策も市場(オッズ)が既に織り込んでいたものが多い

## すでに入っていたもの(二重に補正しない)

- 単勝1倍台は買わない・単勝は2倍以上 → 期待値計算と単勝の帯(4〜9.9倍)。検証でも1倍台は1.05で市場どおり
- 中3週が一番走る → バフェットで検証済み(race_json.pl の中1週 -1・中3〜5週 +1)
- 前走の着差(着順より勝ち馬との差)→ race_json.pl の前走4着以下0.3秒差 +4・0.5秒差 +2
- 危険な人気馬の6項目(距離・芝ダ・回り・競馬場・脚質・近5走)→ favRisks・popDoubts・レースデータの作り方.md
- ワイドは5番人気以内×6〜9番人気、2桁人気は入れない、1番人気×2番人気は買わない → バフェットで検証済み(1〜3番人気同士が82%で一番良く、固定ルールにはしない)
- 3連複は「人気2頭+穴1頭」が万馬券の半分以上、軸は人気馬、3着は広く → 馬券の買い方_3連複.md・trioHint
- 3連複の100倍未満を切る → コタの「200倍未満カット」と同じ(期待値と二重になるので自動カットはしない。synthHint に表示済み)
- 2〜3着が多い馬(善戦型)の単勝は買わない → 単勝の買い方_コタ.md・axisHint の善戦型
- 1番人気が1倍台のときの2番人気以降、単騎逃げ、過去5走すべて1秒以上負け、1番人気の対角線(サイン)、マーチンゲール法、3連単を避ける → バフェットで検証済み・不採用
- ダートの逃げ・先行有利 → simulator の defaultBias(ダートは逃げ・先行 +1.5)。検証でも6〜11番人気の先行型はダートで1.27(前半1.35・後半1.19)・芝0.91で、既存の向きと同じ
- 資金管理(1レース資金の3〜5%、1日の予算)→「1日の予算」タブのケリー配分

## 手で見る目安(自動計算には入れない)

- ダート重賞(G3・オープン): ダートG1・G2を走った経験のある馬は格上の相手と戦ってきた分、人気薄でも見直す(動画の主張、未検証)
- 3歳春のG1・牝馬限定重賞・ハンデ重賞は荒れやすく、3連複の穴を広めに(動画の主張、未検証。重賞の荒れ方は G1の高配当パターン.md・少頭数レースの狙い方.md の方を優先)
- 予想の最終決定は当日、上位人気のオッズが落ち着いてから(シミュレーターは自動更新でオッズを取り直している)
