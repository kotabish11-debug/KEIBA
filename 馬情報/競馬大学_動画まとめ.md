# 競馬大学(@keiba-minami)の動画まとめと検証

- 出典: YouTube「競馬大学」(https://www.youtube.com/@keiba-minami)。2026-10-23に一覧を取得: 通常動画・ショート・ライブ合わせて819本、字幕が取れたのは808本(11本は字幕なし)
  - 予想の考え方・買い方の解説 393本(2021〜2026年)、重賞ごとの予想・有力馬解説 415本(2024〜2026年)
- 話の中身: 初心者向けの一般論(人気別の勝率・控除率・資金管理・買い目を絞る)が大半。芸能人・予想家(じゃい・キャプテン渡辺など)の紹介、買い方の体験談も多い
- 数値は動画内の説明で未検証。下の「検証」は 2026年4〜10月の平場(馬情報/過去レースデータ/、1,871レース)で、勝率÷市場の勝率(1/オッズを正規化)を前半(〜7/14)・後半で比べた結果。買い方は本物の払戻で回収率を出した
- 当日の馬場状態は平場データのレースに入っていないので、各馬の過去走(日付・場所・芝ダ・馬場)から復元して使った
- LINE・オープンチャット・指数サイトの宣伝、メンタルの話は取り込まない

## 結論
**自動計算(race_json.pl・simulator)に新しく入れたものはない。** 数値で確かめられる主張は、市場(オッズ)がすでに織り込んでいるか、前半・後半で向きがそろわなかった。すでに入っている補正と同じ向きのものは下に記録だけ残す。

## 手で見る目安(自動計算には入れない)
- 予想の手順: 馬柱では着順より勝ち馬とのタイム差・通過順・人気と着順の差、映像では出遅れ・不利・直線の伸びを見る(レース映像の見方.md と同じ)
- パドック: 新聞を見る前に見る。歩くリズム・入れ込み(汗・白い泡)・毛づや。2人引きは安全のためのことが多く減点しない(調教の見方.md・馬の走り方と調教.md と同じ扱い)
- 新聞の厩舎コメントで「充実している」「うまく立ち回れば」「展開が向けば」「見えない疲れ」は力が足りない裏返しのことが多い(他人の印・コメントは使わない方針と同じ)
- ハンデ戦: 重いハンデの馬は、その実績が今回と同じ競馬場・距離のものなら重視、違う舞台の実績で背負わされているなら割り引く
- リピーター: 前年の同じレースで好走した馬は、前年との条件の違い(馬場・展開・枠)を見たうえで残す(スワンSのオフトレイル・ワイドラトゥールなど)
- 騎手(2023〜2024年の集計で古い。騎手名が学習データにないため未検証) → [騎手の得意・苦手.md](騎手の得意・苦手.md) の「競馬大学」の節
