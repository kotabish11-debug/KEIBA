# バフェット【プロ競馬投資家】の動画まとめと検証

- 出典: YouTube「バフェット【プロ競馬投資家】」(https://www.youtube.com/@bafetto62)の全100本(通常85本・ショート15本。2026-10-23に自動字幕を取得)
- 動画内の数値は本人の説明で未検証。下の「検証」は 2026年4〜10月の平場(馬情報/過去レースデータ/、約1,800レース・25,000頭)と払戻 1,362レースで確かめた結果
- メルマガ・LINE登録・AIツールの宣伝、精神論(投資の心構え・FIRE・習慣)の部分は取り込まない
- 全体の印象: 「1番人気を疑う」「単勝1倍台は買わない」「人気馬+中穴で組む」「資金は1レース3〜8%」の繰り返しが多く、予想の具体策は少ない。具体策の多くは市場(オッズ)が既に織り込んでいた

## 採用したもの

| 内容 | 動画での主張 | 検証(勝率÷市場の勝率) | 入れた所 |
|---|---|---|---|
| レース間隔 | 中3週が一番走る。間隔が短いと疲れが残る | 中1週 0.89(前半0.86・後半0.92)、中3週1.06・中4週1.12・中5週1.08(前半・後半とも1倍超)、中2週1.00、中6週以上1.00 | race_json.pl: 中1週 choshi -1、中3〜5週 +1。note に「中N週(±1)」 |

## すでに入っていたもの(二重に補正しない)

- 着順より着差: 前走で負けても勝ち馬と0.5秒以内なら巻き返す → race_json.pl が前走4着以下0.3秒差 +4・0.5秒差 +2(調子)。検証でも前走4〜6着・0.5秒以内は市場の1.23倍(前半1.29・後半1.15)で、方向は合っている。最終勝率はオッズ90%混合なので、これ以上足しても変わらない
- 前走の圧勝は過剰人気(前走1秒以上の圧勝の次走は勝率14%) → favRisks の「前走の圧勝」
- 前走2着は人気しすぎ → race_json.pl の choshi -2(単勝の買い方_コタ.md)
- 前走ハイペースで負けた馬の巻き返し → 穴馬の激走パターン.md(前走H・先行・4〜10着 +2)
- 券種ごとに軸を選ぶ(ワイド=3着以内率、馬連=連対率、3連複=安定) → 軸馬と相手の選び方.md・simulator の axisHint
- 「1番人気は勝率約32%・単勝回収率約78%」「単勝1倍台は2回に1回負ける」 → 期待値計算(オッズ90%混合)で扱い済み
- 単勝は4〜10倍の中穴 → 単勝の帯(4〜9.9倍、10倍以上は買わない)と同じ考え
- 危険な1番人気(展開と脚質が合わない・条件替わり・馬場や枠が不利・乗り替わり) → favRisks・popDoubts・g1Hint
- 3連複は1・2着が堅く3着が荒れるレースで、人気馬の軸+6番人気以下の紐 → 馬券の買い方_3連複.md・trioHint
- 資金管理(1レース資金の3〜8%、配当の半分だけ転がす) → 「1日の予算」タブのケリー配分(1レース上限30%)で扱い済み。動画の「資金×0.08÷オッズ」はオッズが高いほど少なく賭ける形で、ケリーに近い

## 手で見る目安(自動計算には入れない)

- 長距離(3000m以上)の重賞: 1番人気が勝ち切れず2・3着が多いとの主張。軸は1〜2番人気、3着に長距離血統の人気薄(オルフェーヴル・ゴールドシップ・ドゥラメンテ・ルーラーシップ・レイデオロ・キズナ産駒など)を広めに。短距離血統の父(ロードカナロアなど)の1番人気は勝ち切れないことがある
- 血統の話(動画内の主張、未検証): キタサンブラック産駒は1600〜2000mが得意で2400m以上は割り引き / キングカメハメハの孫世代(ロードカナロア系を除く)は距離延長に強い / キズナ産駒はG1で2・3着の取りこぼしが多い。種牡馬名がデータに無いので検証できず、血統の系統と国別タイプ.md の考え方の範囲で手で見る
- パドック: 入れ込み(長距離ほどマイナス)・首の使い方・白い汗・外を回るか・腰の柔らかさ・引き手の様子。映像を見たときだけ ±2(レースデータの作り方.md の調子)
- 馬体重は「過去の好走時の体重」と比べる(増減の数字だけで判断しない)
- コース(中山・小倉)の説明は 競馬場の特徴_JRA10場.md と同じ内容。中山芝2500mの8枠不利、中山芝1800mは内枠の先行、中山ダ1200mは先行有利、中山ダ1800mは時計がかかり差しも届く
- 当日の同じコースの勝ち時計・上がりを見て馬場の速さを確かめる → bias.pl の当日バイアスと同じ考え
