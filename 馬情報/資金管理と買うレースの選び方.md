# 資金管理と買うレースの選び方

出典: YouTube「青木」(競馬副業のチャンネル)の「月10万円の競馬副業」の動画(ユーザー提供の文字起こし、2026-10-21)を要約。宣伝・勧誘(LINE登録・個別相談会)の部分は除いた。数値は動画内の説明で、自分で検証したものではない。

## 考え方
- 見るのは**回収率**(払戻÷購入額)。的中率はプロでも2〜3割で、当たったときに5〜10倍をもらって全体でプラスにする
- 目標の回収率は105〜120%。200〜300%を狙うとギャンブルになる
- **全部のレースを買わない**。買うレースが増えるほど、全体の平均(9割が負ける)に近づく。「どのレースを買わないか」と「決めたルールを守れるか」の方が予想の上手さより大事

## 動画の基本の戦術
- 月25レース(週6レース前後)だけ、**単勝で2〜5番人気の中から1頭**を買う
  - 単勝: 1着だけ考えればよく、振り返りやすい。複勝は儲からず、馬連・3連系は初心者には難しい
  - 2〜5番人気: オッズと当たりやすさのバランスが最も良い。1番人気に人気が集まりすぎると、このゾーンが割安になる
- 1頭に絞るのは **騎手(リーディング上位)とコース実績(同じ競馬場・同じ距離での好走)** の2つで十分。慣れたら、前走・近走で勝ち馬から0.3秒差以内かも見る

## 買うレースの選び方(4つ)
1. 狙いたい馬が**1頭に絞れる**レース(絞れなければ見送る)
2. 2〜5番人気に信頼できる馬がいて、**1番人気に不安**がある(期待だけで人気・騎手が弱いなど)
3. **不確実な要素が少ない**: 良馬場 / 10〜12頭くらいの少なめの頭数 / 初めての距離・コースの馬が少ない
4. 候補を絞りやすい**下級の条件戦**(重賞・G1は力の差が小さく荒れやすい)

## 資金管理のルール
- 1レースの金額 = 月の予算 ÷ 25。**自信があっても増やさない**、負けても取り返そうとしない
- 月の予算は、全部なくなっても困らない額にする(例: 5万円で月1万円の利益を目指す → 慣れたら25万円で5万円、50万円で10万円)
- 大きく勝っても、その月の途中では金額を変えない。増やすのは翌月から
- ネット投票用の口座は競馬専用にして、その月の予算だけを入れる

## 振り返り
- 買ったレースは**その日のうちに**、選んだ理由と結果を1〜2行でメモする(体調・集中力などの気づきも)
- メモは残しておき、次に同じ条件・同じ馬・同じ騎手を狙うときに見返す
- 参考にするやり方を短期間でころころ変えない(最低1か月は続けて検証する)

## シミュレーターとの関係
- すでにあるもの: 単勝は4〜9.9倍(おおむね2〜5番人気)を中心に選ぶ / 期待値が足りなければ見送り / ★(自信の高いレース)/ 「1日の予算」タブで1レースの上限30% / 東京・京都・新潟の全レースの自動の振り返り
- 違う点: シミュレーターは自信(期待値と的中率)に応じて金額を変える(ケリー基準)。動画は「1レースの金額は固定」を勧めている。熱くなって金額を増やすのを防ぐのが目的なので、シミュレーターの推奨額より多くは買わないことで同じ効果になる
- 手で予想するときは、上の「買うレースの選び方」で見送りを増やす

## オッズの断層で勢力図をつかむ(2026-10-21追加)
出典: YouTube「青木」のオッズの断層の動画(ユーザー提供の文字起こし)を要約。

- 予想の起点は「そのレースの上位の馬を把握して比べること」。穴馬が来るのも、上位の馬の中に危ない馬がいてその枠が空くから。人気順(1〜5番人気)は目安で、同じ5番人気でも8倍と20倍では立ち位置が違う
- **断層** = 単勝を人気順に並べ、隣の馬のオッズが**2倍以上**離れている所(割り算で見る。引き算だと人気薄ほど差が大きく見える)。断層の上の馬は好走しやすく、下の馬は凡走しやすい傾向
- ただし断層の上を機械的に買うだけでは勝てない(多くの人が知っている)。**上位の馬をどこまで見ればいいかを知る道具**として使う
- 4つの型
  1. 1番人気だけ抜けていて、素直に強そう → 当たっても配当が見合わないので見送り(例: 2025年マイルCS ジャンタルマンタル1.8倍・2番人気5.2倍)
  2. **1番人気だけ抜けているが不安がある → 最も狙い目**。2番人気以下(1番人気の倍以上のオッズ)から逆転候補を選ぶ(例: 2026/2/28 阪神1R。1.9倍の1番人気は京都の平坦コースだけで好走していて今回は急坂の阪神。4.6倍の2番人気は前走6着でも、スローで差しが届かない流れで上がり最速・2着と0.3秒差。距離延長と坂で条件が好転し、勝利)
  3. 上位2〜3頭が拮抗して、その下に断層 → その2〜3頭の中で比べて1頭を選ぶ(例: 2026/1/10 中山11R。2.5倍の1番人気は前々走の圧勝が馬場と斤量に恵まれたもの、5.0倍の3番人気は前走の大敗が適性外の新潟外回りで、得意の中山に戻って勝利)
  4. 上位5〜6頭のオッズが割れて断層がない混戦 → 絞れる材料がなければ見送り(例: 2025年ホープフルS)
- オッズを見るのは自分が予想するタイミングで十分(断層に丸乗りするのではなく、参考にするだけなので)

## ネット競馬(netkeiba)の使い方(2026-10-21追加)
出典: YouTube「青木」のネット競馬の活用法の動画(ユーザー提供の文字起こし)を要約。有料プラン(スーパープレミアム、月1390円)の機能を含む。

- AI予想や予想家の印に丸乗りしない(自分の予想力が上がらない)
- 出馬表の「競馬新聞」表示で近走をまとめて見る。**着順だけで判断せず着差も見る**(同じ2着でも0.1秒差と1秒差では違う)。ペース・位置取り・上がり3Fから「負けたのは展開のせい」なども読む。気になるレースは結果ページに飛び、**戦ってきた相手のレベル**(勝ち馬や後ろの馬のその後)を確かめる
- お気に入り馬とメモ: 次に出走すると通知が来る。メモに残すのは「力があるのに出せずに負けた馬」と「恵まれて勝った馬」。ただし**メモがあるから買う、ではない**(今回の相手と比べる普通の予想を怠らない)。メモは自分が予想したレースだけで十分
- タイム指数: 走破タイムを馬場やペースで補正した数値。補正は完璧ではない(高速馬場・短距離・ローカルは高めに出やすい)ので、1〜2の差は気にせず大まかな上下で見る。**近5走の平均ではなく最高値**を見る(力を出し切ればどこまで走れるか)。それを今回出せるかは適性で判断する

## シミュレーターへの反映(2026-10-21)
- オッズの断層: レースの画面に4つの型のどれかを表示する。型2(抜けた1番人気に不安)は、シミュレーターの能力値からの勝率が市場の勝率の8割未満のときに出る
- 着差: 全レースの自動計算で、前走の着差を「調子」に反映(4着以下でも勝ち馬と0.3秒差以内 +4・0.5秒差以内 +2 / 2〜3着でも1.0秒以上 -4・0.6秒以上 -2 / 0.5秒以上の完勝 +2)
- 注目馬メモ([注目馬メモ.md](注目馬メモ.md))は「メモがあるから買う、ではない」の考え方ですでに運用している

## 「7かバチか」: 勝負する基準(2026-10-21追加)
出典: YouTube「競馬さラジオ」の、本『勝率9割の選択』(プロギャンブラーのぶき)の紹介回(ユーザー提供の文字起こし)を要約。考え方の話が中心で、数値の根拠は示されていない。

- **1か8か(バチか)ではなく7か8か**: 自分の見込みで7割以上当たると言える勝負だけをする。2倍でも的中率7割なら回収率140%、3倍なら210%。「5倍だから5回に1回当たればいい」という甘さが、外れを運のせいにする原因になる
- **競馬の最大の強みは、勝負するレースを自分で選べること**。見送っても誰にも引け目はない。確信の高いレースだけに絞る
- **勝負は準備で9割決まる**(準備90%・本番10%)。アマチュアは結果にこだわり、プロは勝つための準備にこだわる
- **スランプはない。それが実力の底**: 1日単位では運で負けても、長い期間(本では30日、競馬なら3か月〜半年)では実力どおりになる。悪いときでもここまでは当たるという自分の最低ラインを知る。負けの原因は運ではなく、予想の精度・選び方・ルールの甘さに求める
- **相手の視点に立つ(思考の3段階)**: 1=自分の手札だけ(出馬表だけ)、2=相手がどう動くか(展開・他の馬)、3=相手から見た自分。競馬では陣営・騎手の目線で「なぜこの馬をこのレースに使ってきたか」「自分が騎手ならどう乗るか」を考える
- **水になれ**: 自分の勝ちパターンも疑う。ファンの予想のレベルが上がり(AIも使われる)、締切直前に人気が大きく動き、馬場も高速化している。昔の理論(ラップなど)も通用しなくなる可能性がある
- **勝負力 = 理論 × 経験**(足し算ではなく掛け算)。知識だけでは勝てず、買って外して反省して直す経験と結びついて力になる
- **生活コスト(固定の出費)を上げない**: 出費が増えると無理な勝負や焦りが増える。負けても崩れない資金があると、見送るべきレースを見送れる

### シミュレーターとの関係(取り入れ方)
- 「7割以上」をそのまま買う条件にはしない。単勝2倍は市場の見込みで勝率4〜5割程度で、それを7割と見込めるほど市場とずれるレースはまれ(見込み違いのまま勝負すると負ける)。シミュレーターは「期待値が1.1以上の馬券だけ買う・なければ見送る」で同じ考え(確信のあるときだけ勝負)を数値で行っている
- 7割に近いのは、軸として3着以内に入る確率。★(◎の3着以内率が80%以上で1番人気)のレースが「7か8か」に当たる。軸に絞って複勝・ワイドで2〜3倍を取りにいく形
- 「実力の底」は振り返りの記録([予想と結果_レース.csv](予想と結果_レース.csv))で、月ごとの◎の3着以内率と回収率を見て確かめる。1日の負けで重みや基準を変えない(重みの最適化は記録全体で行っている)
- 「水になれ」は、能力値の重みと★の基準を振り返りの記録から自動で調整し直す仕組みで、すでに取り入れている
- 「陣営の目線」は重賞の判断材料で手で見る([情報収集の手順.md](../情報収集の手順.md) の2-2)
