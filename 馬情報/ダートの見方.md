# ダートの見方(砂かぶり)

出典: YouTube「青木」のダート攻略の動画(ユーザー提供の文字起こし、2026-10-21)を要約。LINE登録などの宣伝部分は除く。数値は動画内の説明で未検証。

## なぜダートが狙い目か
- 芝はトラックバイアス(内・外どちらが伸びるか)が日ごとに変わり、出馬表だけでは読みにくい。ダートは芝ほど複雑ではない
- ダートは距離の種類が少なく、同じ競馬場・同じ距離を何度も走っている馬が多い。過去のレースと比べやすく、条件が変わったときはその変化に注目すればよい

## 本質: 砂をかぶるか
- 前の馬が蹴り上げた砂を顔や体に浴びると、嫌がって力を出せない馬が多い。能力が高くても、それを出せるかどうかを大きく左右する
- 下のクラスを圧勝してきた馬が上で崩れるのも、砂かぶりの影響が大きいことがある。逆に、砂をかぶって負けて人気を落とした強い馬が、今回は砂をかぶらずに走れそうなら狙い目

## 見るポイント
1. **砂をかぶらずに走れるか = 脚質と枠順**
   - 逃げ・先行(特に逃げ馬の外に並ぶ先行馬)は砂をかぶらない。差し馬は馬群で我慢すると砂を浴び続け、外を回すと距離のロスになる。芝以上に前が有利
   - 外枠が有利。内枠はダッシュを決めて前に行ければ最高だが、少しでも出遅れると外の先行馬にかぶされて囲まれ、取り返せない。外枠は先手を取れなくても外を回して砂を避けられる
   - データ(2021〜25年のダート全体): 勝率 1枠6.5%、1〜3枠は6%台、4〜7枠は7%台、8枠8.1%。複勝率も同じ傾向
   - 芝スタートのコースは外枠ほど芝を長く走ってダッシュがつくので、さらに外枠有利
   - 内枠の馬は、過去の通過順・前半3ハロンの速さ・スタートのうまさでダッシュ力を確かめる。最初の並び(隊列)を読むのが最重要で、短距離と、コーナー4回の1800mでは特に結果に直結する
   - 例外: **中京ダ1800は内枠有利**。スタート直後に上り坂でペースが落ち、1角まで短いため、外の馬が内に入る時間がなく外を回される
2. **馬場状態**
   - 良馬場(乾いた砂)は砂が軽く大きく舞い、砂かぶりの影響が大きい。パワー型が有利
   - 道悪は砂が締まって舞いにくく、砂かぶりの影響が小さい。スピードが出るので、スピード型(芝でも走れる血統など)が走りやすく、前が止まりにくい(芝の開幕週と同じ)
3. **砂をかぶっても走れる馬**(クラスが上がるほど大事)
   - 下のクラスは前に行って砂を避けた馬が強い
   - 3勝クラス・オープンになると、前で勝ってきた馬が集まって先行争いが激しくなりペースが上がる。すると、砂をかぶりながら中団で我慢して最後に伸びる差し馬が台頭する
   - 見抜き方: 過去に内枠や馬群の中で砂をかぶる形でも好走したか。着順が悪くても、勝ち馬と僅差なら内容は悪くない

## シミュレーターへの反映(2026-10-21)
- simulator.html
  - ダートの枠の補正の初期値を「内枠有利(+0.5)」から「外枠やや有利(-0.2)」に直した(それまで動画・[競馬場の特徴_JRA10場.md](競馬場の特徴_JRA10場.md) と逆だった)。芝スタートのダートは従来どおり -0.3、コース別の設定があるコースはそちらを使う
  - 中京ダ1800 をコース別の設定に追加(逃げ・先行有利、内枠有利 +0.5)
  - ダートの重・不良では、外枠有利の補正を半分にする(砂が舞いにくい)。道悪で逃げ・先行に +0.5 は従来どおり
- 全レース自動計算(race_json.pl、`choshi`)
  - 近5走のダートで内枠から馬群の中を通って好走(3着以内か0.3秒差以内)した差し・追込馬は、3勝クラス・オープンなら +2(砂をかぶっても走れる)
  - そうした好走がなく、内枠で砂をかぶって凡走(6着以下・0.6秒以上)しかない差し・追込馬が今回も内枠なら -2
  - 前走外枠で好走 → 今回内枠の -3 などは従来どおり
- 手で付ける基準は [レースデータの作り方.md](../シミュレーター/レースデータの作り方.md) に追記
