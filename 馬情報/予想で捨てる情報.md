# 予想で捨てる情報(ノイズ)

出典: YouTube「上昇」の「競馬で捨てるべき情報5選」(ユーザー提供の文字起こし、2026-10-21)を要約。
ノイズ = はっきりせず、主観が混じり、同じ結果を再現できない情報。予想は、時計・血統・コース適性など動かない事実を積み上げて作る。

| 捨てる情報 | 理由 | 例外・使い方 |
|---|---|---|
| パドック解説・直前のSNSの評判 | 解説者の主観で、当たっても外れても後から説明できる言葉。買う直前に入ってきて、積み上げた根拠を崩す | パドックそのものは否定しない。自分だけが読み取れることがあるなら使う |
| 理由を説明できない過去データ | 「過去10年で8枠の勝率が高い」も、強い人気馬がたまたま8枠に入っただけかもしれない。数が少ないと傾向とは言えない。馬場やメンバーは毎年変わる | コースの形(直線の長さ、1コーナーまでの距離、芝スタートなど)という理由があるデータは使う |
| 騎手の最近の調子 | 好不調は、乗った馬の強さ・展開・開催のメンバー(有力騎手がいるか)でほぼ決まる | — |
| 乗り替わりの強化・弱化 | 強化なら人気が上がりオッズが下がる、弱化ならその逆で、オッズに織り込まれている | 以前その馬で好走した騎手に戻る「手戻り」は評価する |
| 馬体重の増減 | 絞れたのか、ただ減ったのか、成長か、太め残りかは外から分からない。推測は再現性がない | 2桁の増減のときだけ、(1)好走したときの馬体重に近いか、(2)2〜3歳はプラスは成長、マイナス2桁は割引、を見る |

## 馬体重の詳しい見方(「馬体重」の動画、2026-10-21追加)
- 大前提: 大きい馬ほど有利(400kg未満の複勝率約7%、500kg台は約25%。回収値も上がる)。斤量は48〜59kgの狭い範囲なので、体が大きいほど負担が軽い
- -10〜-19kgは、ちょうどいい増減の馬とそれほど差がない。-20kg以上は複勝率約10%・単勝回収値47と大きく落ちる
- +20kg以上は複勝率は少し下がるが、単勝回収値93で全区分の中で最も高い(嫌われてオッズが上がるため)
- 理由を読む5つの視点: (1) 滞在競馬(北海道・小倉)で減っていたら危険 (2) 長距離輸送で減るタイプかを過去の遠征で確認 (3) 好走したときの馬体重に近ければ心配いらない (4) 2〜3歳の増加は成長、6歳以上の大幅増は太め残り (5) 夏の減少は夏バテの恐れ

## シミュレーターへの反映(2026-10-21)
- パドックは計算に使っていない。馬体重の増減は、全レースの自動計算で「はっきり悪いサイン」のときだけ `choshi` を下げる: -20kg以上 -4、2〜3歳のマイナス2桁 -2、夏(6〜9月)・滞在競馬での減少 各-1、6歳以上の+10kg以上 -2
- 馬格は `jisseki` に反映: 420kg未満 -2、500kg以上 +1(新馬戦は別のルール)
- 騎手の点数は、リーディング・重賞実績(重賞)と、このコースでの連対率(全レース自動)で付けていて、ここ数週の調子は使っていない
- 判断材料(過去10年)からの補正は、理由を説明できる傾向だけにし、数が少ない傾向は小さくする(手順は [情報収集の手順.md](../情報収集の手順.md) の「2-2」)
- シミュレーターは期待値で買うので、人気(オッズ)が下がった馬ほど期待値が上がるという考え方とも合っている

## 捨てるべき情報7つ(YouTube 青木「予想する時に捨てるべき情報7つ」、2026-10-21追加)
出典: ユーザー提供の文字起こしを要約(LINE登録などの宣伝部分は除く。数値は動画内の説明で未検証)。
考え方の軸: 見るのは「能力があるか」と「それを発揮できるか」だけ。理由(仮説)を説明できない情報は捨てる。使うなら「こうだったらこうする」を事前に決めておく。

| 捨てる情報 | 理由 | 使ってよい形 |
|---|---|---|
| 他人の予想 | 「当たる人を探すゲーム」になり、予想が二重に難しくなる。3週連続的中も偶然の連続にすぎない | 結論に至った考え方(ロジック)を学ぶためなら参考にしてよい |
| 前走の着順だけ | 同じ2着でも0.1秒差と1秒差は別物。強いメンバーの6着が手薄な相手の2着より上のこともある | 着差・メンバー・展開(ハイペースで外を回された/スローの2番手で楽に残った)とセットで見る |
| 理由のないデータ | 過去10年=10レースしかない。3枠が強いのは人気馬がたまたま入っただけかも | コースの形などで理由を説明できるもの(例: 中山ダートの外枠有利=芝スタート+1角まで長い)だけ使う。「1番人気0勝」も、毎年混戦になる構造が今年も同じなら考慮 |
| 騎手の調子 | 先週3勝しても馬が強かっただけかもしれない。根拠が薄すぎる | 上位騎手への乗り替わり、先行が得意な騎手×先行で持ち味が出る馬、長距離は騎手の腕・短距離は減量騎手のダッシュ、などは仮説として見てよい |
| 馬体重の増減 | ±10kgでどれだけ変わるかは分からない。直前になんとなく印を変えるのは再現性がない | 事前に「-○kg以上なら評価を下げて○と○を入れ替える」と決めておく。休み明け+14kgでも、休み前に減り続けていたなら戻しただけ |
| パドックの気配 | 「良さそう」「入れ込んでいる」の影響は分からない。当たっても偶然 | 「入れ込むと走らない馬」など、その馬の過去のパドックと結果から作った仮説があるときだけ使う |
| 調教タイム | 単発の時計に意味はない(50m 8秒も、ベスト7秒台なら不調、9秒台なら絶好調) | その馬のこれまでの調教と比べた変化を見る。それも能力・適性を見たうえでの微調整(本数・強さ・コースの変化は [調教の見方.md](調教の見方.md)) |

### シミュレーターへの反映
- すでに入っているもの: 着差の補正(全レース自動・`choshi`)、騎手の最近の調子を使わない、馬体重は事前に決めた条件のときだけ補正、理由を説明できる過去データだけ使う(2-2)
- 追加(手で付ける基準、[レースデータの作り方.md](../シミュレーター/レースデータの作り方.md) の「使わない情報」): 他人の予想の印は使わない / パドックは事前に決めた条件のときだけ / 調教は自己比較で ±2 / 前走の中身(スロー2番手の楽な好走 -2、ハイペース外回しの小差凡走 +2)/ 休み明けの大幅増は休み前に減り続けていたなら減点しない
- 全レース自動計算には入れていない(前走のペースや調教の時計は自動取得していないため)

## 来ない馬から予想する(netkeiba「明日から使える馬券の金言」、2026-10-21追加)
出典: YouTube「ネット競馬」の、ゲスト(じゃい)の回(ユーザー提供の文字起こし)を要約。

- 多くの人は「どれが来るか」から考え、人気馬・印のある馬だけを見る。**来ない馬が分かる方が当たる**。1頭消せれば点数も絞れる(総流しか、相手を絞るかの判断にも使える)
- 穴馬は印のない馬から生まれる。「単勝100倍だから来ない」と見捨てず、**人気のない馬こそ入念に**調べる(過去のレース、デビューのころ、血統、得意な馬場、騎手との相性)
- どう予想しても買えない馬が来ることはある。それで「もっと広げておけば」と点数を増やすのは負けへの道。**自分のミスか、偶然か**を区別し、買い方の芯をぶらさない
- 好き嫌いで買わない(応援はしても、過剰に売れる馬は買わない。例: 凱旋門賞の日本馬)
- 使う額は最初に決めておく

### シミュレーターとの関係
- シミュレーターは全頭を同じ基準で計算するので、人気・印で見捨てる馬はない(全レース自動計算も全頭に同じ補正をかける)
- 手で能力値を付ける重賞でも、人気薄を後回しにしない([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md) に追記)
- 外れた後に点数を増やさないことは、予算ごとの点数の上限(1000円まで2点、2000円まで3点)で守られている
