# 危険な人気馬と単勝の狙い方

出典: YouTube「上昇」の「危険な人気馬の見抜き方5選」と「単勝の狙い方」(ユーザー提供の文字起こし、2026-10-21)を要約。数値は動画内の説明で、自分で検証したものではない。

## 危険な人気馬(5つ)と、その逆の狙い目
前走の好走が「条件に恵まれた」ものなら、条件が変わると再現できない。逆の条件なら巻き返しの狙い目になる。

| 危険な人気馬 | 理由 | 逆の狙い目 |
|---|---|---|
| 前走逃げて好走 | 逃げは力を出し切りやすいが再現性が低い。人気の逃げ馬はマークされ、同型がいればペースが厳しくなる(例: 2025年チャンピオンズCの1番人気が13着) | — |
| 半年以上の休み明けで1〜3番人気 | 実績と騎手で買われるが、状態が万全でないことが多い(動画では単勝回収率67%。例: 2026年京都記念のヘデントール) | — |
| 前走は道悪(重・不良)や強風で好走、今回は良馬場 | 道悪では適性が能力を上回る。条件が戻ると評価は逆転(例: 2024年京都大賞典のブローザホーン) | 道悪で凡走した実力馬が良馬場に戻る |
| 芝で前走内枠 → 今回外枠 | 内ラチ沿いのロスのない競馬が再現できない(動画の例: 2025年のG3で、前走1枠1番から内を回って大勝した1番人気が、大外枠で外を回され8着) | 芝で前走外枠で凡走 → 今回内枠 |
| ダートで前走外枠 → 今回内枠 | 砂をかぶるのを嫌がる馬が多い。外枠なら多少ロスがあっても砂をかぶらずに進める | ダートで前走内枠で凡走 → 今回外枠 |
| ダートで前走牝馬限定 → 今回牡馬混合の牝馬 | ダートはパワーが要り牡馬が有利(動画ではこの条件の勝率8%) | 牡馬混合で負けた牝馬が牝馬限定に戻る |

## 単勝の狙い方(7つ)
単勝の払戻率は80%で、ほかの券種(72.5〜77.5%)より高い。1着だけ考えればよく、1点に資金を集められる。

1. **オッズ帯は4〜9.9倍**: 3.9倍以下は勝ち切る難しさに対して戻りが小さく、10倍以上は2・3着止まりが増える(動画では過去5年でこの帯の回収率が最も高い)
2. **前走4〜6着の馬**: 前走1〜3着は目立って人気が出すぎる。7着以下は力も落ちる。その中間が狙い目
3. **条件が好転する馬**: 前走の着順は地味でも、今回は条件がそろう馬
4. **迷ったら若い馬**: 年齢が上がるほど勝率が下がる
5. **逃げ・先行を優先**: 単勝では前で運べる馬の勝率が差し・追込の3倍以上。本来は先行できるのに前走は展開が合わなかった馬は、10倍以上でも狙える
6. **勝つか大敗かの馬(2・3着が極端に少ない)**: ハマれば勝つタイプ。人気を落としたときが狙い目(例: ゴールドシップ。ダートのアメリカンファラオ産駒は、逃げたときや外枠で砂をかぶらないときに走る)
7. **レースを選ぶ**: 危険な人気馬がいるレースは単勝向き(その馬を迷わず外せる)。1倍台の人気馬が素直に強いレースは見送る(1倍台の勝率は約55%)

## シミュレーターへの反映(2026-10-21)
- 全レースの自動計算(`自動実行/全レース/race_json.pl`)で、前走欄(通過順・馬番・馬場)から次を `choshi` に反映。理由は各馬の `note` に出る
  - 前走逃げて3着以内 -2。ほかにも逃げ馬がいれば さらに -2
  - 半年以上(中26週以上)の休み明け: これまでの -6 に加えて -3
  - 前走が重・不良で3着以内、今回が良 -3 / 前走が重・不良で6着以下、今回が良 +2(今回の馬場は当日発表後に効く)
  - 芝: 前走内枠(頭数の内3割)で3着以内 → 今回外枠(外3割) -3 / 前走外枠で4着以下 → 今回内枠 +2
  - ダート: 前走外枠で3着以内 → 今回内枠 -3 / 前走内枠で4着以下 → 今回外枠 +2
- シミュレーター本体: 単勝は4〜9.9倍を中心に選ぶ。3.9倍以下と10倍以上は、期待値が条件より0.2以上高いときだけ買い目に入れる
- 1倍台の素直に強い人気馬・危険な人気馬の扱いは、期待値で買い目を選ぶ仕組みで自然に扱われる(期待値が足りなければ見送り)
- 自動では見ていないもの(牝馬限定→混合、勝つか大敗かの馬、若い馬、前走4〜6着の割安さ)は、重賞で手で付けるときの基準にした([レースデータの作り方.md](../シミュレーター/レースデータの作り方.md))

## 1番人気の成績(飛ぶ1番人気・堅い1番人気、2026-10-21追加)
出典: YouTubeの「飛ぶ1番人気の特徴と硬い1番人気の条件」(チャンネル名不明、ユーザー提供の文字起こし)を要約。過去3年・約1万レースの集計。数値は動画内の説明で未検証。

- 全体: 1番人気の勝率33.5%・連対率約53%・複勝率約66%。芝とダートの差は小さい(ダートがやや上)
- オッズ: 1.4倍以下は勝率68.3%・複勝率9割超。1.9倍以下で勝率45.4%。2〜2.9倍が最も多く平均並み。3倍以上ははっきり下がる
- 間隔: 中1週〜半年はほぼ同じ。連闘は悪い。半年以上の休み明けは数が少ないが「勝つか大敗か」
- 脚質(今回): 前に行くほど良い。逃げたときは勝率50.5%で単勝・複勝の回収率とも100%超。追込は悪い(出遅れを含む。スタートの悪い馬の1番人気は注意)。まくりは良い
- 前走の脚質: 前走先行が最もバランスが良い。**前走逃げは良くない**、前走追込も良くない(上がりだけ速くて人気になる馬は注意)
- 前走着順: 前走2着が最も良い(勝率約36%。前走1着は昇級で相手が強くなる)。着順が下がるほど悪く、前走10着以下は悪い
- クラス: **G1は1番人気の勝率が高い**(回収率100%超)。**オープン特別とG2・G3は悪い**(勝率26%前後)。新馬〜2勝クラスは良い
- 馬場: **芝は馬場が悪くなるほど1番人気が悪い**。ダートは不良を除き、馬場が悪いほど良い(脚抜きが良くスピードが出る)
- 頭数: 少ないほど良い。10頭未満が境目
- 馬番(16頭立て): 芝は奇数番(先入れ)が悪い傾向。**ダートは14番より外の1番人気が良く、6・7番など真ん中が悪い**(外と比べ勝率が倍近く違う)
- 芝の距離: 長いほど良い。マイル以下が悪く、1800m以上で安定
- 斤量: 57.5〜59kgの1番人気が最も悪い(ハンデ戦のトップハンデなど。条件で変わるので参考程度)
- 馬体重: 420kg未満の1番人気が悪い
- 年齢: 5歳から勝率が下がる。7歳以上は1番人気になること自体が少ない

### シミュレーターへの反映(2026-10-21)
- レース画面の「オッズの断層」の欄に、1番人気の不安材料を出す: 追込 / 前走逃げて好走 / 馬体重420kg未満 / 芝の重・不良 / ダートの内枠(差し・追込)/ 芝1400m以下。1番人気が抜けている型でも、不安材料があれば「逆転候補が狙い目」の型として出す
- ★(自信の高いレース)は、1番人気が 追込・前走逃げて好走・馬体重420kg未満・芝の重・不良 のどれかに当てはまれば付けない(`自動実行/全レース/star.pl`)
- 能力値そのものは変えていない。勝率はオッズと混ぜて計算しているので、人気の偏りの多くはすでに入っていて、二重に引かないため
- 自動では見ていないもの(G1は堅い・OP特別とG2・G3は飛びやすい、斤量57.5kg以上、5歳以上、連闘)は、重賞で手で見るときの目安にする
