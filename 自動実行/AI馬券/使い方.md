# AI馬券(2026-10-30〜)

「競馬予想で始めるデータ分析」の競馬AIを手元のデータで作り直したもの(検証の記録: [馬情報/的中率を上げるための検証.md](../../馬情報/的中率を上げるための検証.md) の 26)で、単勝を自動で選び、買う。

## 1日の流れ(day.ps1。タスクスケジューラ「競馬_AI馬券」が毎朝 8:30)
1. `morning.sh`(約15分): JRA-VAN の差分(出馬表・調教)→ 先週までの結果(jra_history.sh)→ 今日の出馬表(`entries.py`)→ 特徴量(`自動実行/検証/lgbm_features.py`・`lgbm_chokyo.py`)。中央競馬の無い日はここで終わる
2. `live.py`: 各レースの **発走4分前** に JRA公式の単勝オッズ・馬体重を取り、AIの勝率 × 単勝オッズ(期待値)が **1.0以上・30倍未満** の馬を選ぶ(1レース3頭まで、1日 dailyMax 円まで)。mode に従って買う
3. 最終レースの30分後: JRA-VAN の成績で結果を埋め(`settle.py`)、`馬情報/AI馬券/記録.csv`・`成績.md` をコミット

## 設定(config.json)
| 項目 | 今の値 | 意味 |
|---|---|---|
| mode | **dry** | dry = 記録だけ(買わない)/ browser = 即PATで購入の手前まで進めて戻る / live = 本当に買う |
| stake | 100 | 1点の金額 |
| dailyMax | 3000 | 1日の上限 |
| evMin・oddsMax | 1.0・30 | 買う条件 |
| leadMin | 4 | 発走の何分前に判断するか(即PATの締切は発走2分前) |

## 即PATで買うまでの手順
1. `%USERPROFILE%\.ipat.env` を自分で作る(リポジトリには置かない):
   ```
   INET_ID=...
   KANYUSHA=...(加入者番号)
   PIN=...(暗証番号)
   PARS=...(P-ARS番号)
   ```
2. 発売中に確かめる(買わない。購入の手前で止まる): `python 自動実行/AI馬券/ipat.py --check 東京 11 1 --show`
   - 各手順の画面が `馬情報/JRA-VAN/AI馬券/ipat/` に残る。即PATの中の画面は作った時点で確かめていないので、ここで止まったら画面を見て直す
   - 通ると `ipat_ok.txt` ができる。**これが無いと mode = live でも買わない**
3. config.json の mode を browser(数日)→ live にする

## モデルの作り直し
```bash
PY="$LOCALAPPDATA/Programs/Python/Python312/python.exe"
$PY 自動実行/検証/lgbm_features.py 馬情報/過去レースデータ/全期間 馬情報/JRA-VAN/馬DB <作業>/feat.pkl
$PY 自動実行/検証/lgbm_chokyo.py <作業>/feat.pkl 馬情報/JRA-VAN <作業>/feat2.pkl
$PY 自動実行/AI馬券/train.py <作業>/feat2.pkl 2023-12-31     # → 馬情報/JRA-VAN/AIモデル/(PCだけ)
```
終わった日を当日として流して確かめる: `entries.py <日付> e.jsonl` → `lgbm_features.py ... --until=<その日> --extra=e.jsonl` → `lgbm_chokyo.py ... --upcoming` → `live.py <pkl> e.jsonl --date <日> --replay 1`(締切1分前の JRA-VAN の時系列オッズを使う。記録は replay_記録.csv)

## 注意
- 回収率100%超えは **まだ確かめられていない**(検証26: 締切1分前 117.9%・6分前 102.7%、1年分で単勝のぶれ ±15〜20%)。まず dry で数週間記録する
- 即PATの利用規約で自動の投票がどう扱われるかは確かめていない
- PC が 8:30〜最終レースまで起きていて、JRA-VAN(JV-Link)が使えることが前提
