# JRA公式YouTubeの調教動画・ライブ配信の使い方(2026-10-26〜)

JRA公式YouTube(https://www.youtube.com/@jraofficial)には、重賞ごとの【調教動画】(出走馬の最終追い切り)が上がる。
馬ごとに「追い切り日・コース・馬場・併せの内外」と **調教タイム(競馬ブック提供)** が字幕で出るので、静止画で読み取れる。
Claude は動画を直接見られないので、`jra_chokyo.sh` で4秒おきの静止画を 4×5 の一覧画像(sheet_*.jpg)にして Read で見る。
動画・画像はコミットしない(自動実行/YouTube/映像/ は .gitignore)。

## 1. 毎回(PC収集のたびに)
1. `bash 自動実行/YouTube/chokyo_all.sh` を実行する(一覧を作り直し、まだ読んでいない調教動画を全部、文字認識で読んで `馬情報/調教タイム_JRA動画_自動.tsv` を作り直す。1本1分ほど。スクリプトだけで動く)
2. `馬情報/2026年_重賞一覧.md` の未実施で8日以内の重賞の調教動画が新しく読めたら、その重賞の判断材料ファイル(馬情報/<日付>_<レース>_判断材料.md)に「## 調教(JRA公式の調教動画)」を作り、自動.tsv のその動画の行を表にする。空欄が多い馬だけ `bash 自動実行/YouTube/jra_chokyo.sh get <動画ID>` の一覧画像を Read して埋める(推測で埋めない)。字幕の馬名の前の番号は馬番ではない
3. **能力値・★・買い目は変えない**(2026-10-26 の検証で、調教タイムはオッズ以上に当たらなかった。`馬情報/的中率を上げるための検証.md` の14)。表は参考として載せるだけ
4. 見終わった 映像/調教_<ID>/ の動画は大きいので、月に1回 `馬情報/削除したもの/` に移す(ocr.tsv は残す)

## 2. 検証のやり直し
- `馬情報/調教タイム_JRA動画_自動.tsv` が1,600頭を超えたら(2026-10-26 は900頭)、`perl 自動実行/検証/chokyo_eval.pl 馬情報/調教タイム_JRA動画_自動.tsv,馬情報/調教タイム_JRA動画.tsv 馬情報/過去レースデータ/全期間 <データの真ん中の日>` で確かめ直し、検証資料の14に追記する。前半・後半とも |z| が2を超える条件が出たときだけ、予想に入れる案をユーザーに出す

## 3. ライブ配信のパドック(2026-10-31・11-01 に試す)
- JRA公式は土日に「中央競馬全レース中継」をライブ配信する。パドックが映るかを確かめるため、タスクスケジューラ「競馬_ライブ録画_20261031_1450」「…_20261101_1450」が14:50から45分録る(`live_rec.sh`。メインレースのパドックの時間帯)
- 録れたら(自動実行/YouTube/映像/ライブ_<名前>/sheet_*.jpg)、Read して `馬情報/パドック/ライブ配信の確認.md` に書く: パドックが映ったか、何頭がどれくらいの時間映るか、馬番・馬名が読めるか、画質で毛づや・発汗・歩様が分かるか
- パドックが映っていれば、そのレースの結果を見る前に、馬ごとに A良い/B普通/C悪い と見たことを `馬情報/パドック/判断の記録.csv` に書く(判断時刻の列に「録画を後で判断」)
- 使えそうなら、毎週の重賞の発走30分前から録って、発走前に判断する仕組みを作る案をユーザーに出す
