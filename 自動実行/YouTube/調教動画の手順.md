# JRA公式YouTubeの調教動画・ライブ配信の使い方(2026-10-26〜)

JRA公式YouTube(https://www.youtube.com/@jraofficial)には、重賞ごとの【調教動画】(出走馬の最終追い切り)が上がる。
馬ごとに「追い切り日・コース・馬場・併せの内外」と **調教タイム(競馬ブック提供)** が字幕で出るので、静止画で読み取れる。
Claude は動画を直接見られないので、`jra_chokyo.sh` で4秒おきの静止画を 4×5 の一覧画像(sheet_*.jpg)にして Read で見る。
動画・画像はコミットしない(自動実行/YouTube/映像/ は .gitignore)。

## 1. 今週の重賞(PC収集のたびに)
1. `bash 自動実行/YouTube/jra_chokyo.sh list` で一覧(馬情報/JRA公式_調教動画一覧.tsv)を作り直す
2. 一覧に、`馬情報/2026年_重賞一覧.md` の未実施で8日以内の重賞の調教動画があり、`自動実行/YouTube/調教動画済み.txt` に無ければ `bash 自動実行/YouTube/jra_chokyo.sh get <動画ID>`
3. sheet_*.jpg を全部 Read し、馬ごとに1行ずつ `馬情報/調教タイム_JRA動画.tsv` に足す(列は既存の行に合わせる。坂路の 800m・600m・400m・200m は 4F・3F・2F・1F に入れる。読めない数字は空にする。推測で埋めない)
   - 字幕の馬名の前の番号は馬番ではない(登録順など)。書かない
   - 併せ馬で、最後の静止画で前に出ていれば「先着」、並んでいれば「同入」、後ろなら「遅れ」とメモに書く(はっきりしないときは書かない)
4. その重賞の判断材料ファイル(馬情報/<日付>_<レース>_判断材料.md)に「## 調教(JRA公式の調教動画)」を作り、表と目立った点(終いが速い・遅れた・単走で軽め など)を書く
5. 能力値・印はまだ変えない(調教タイムが当たりに効くかは未検証。下の3で確かめてから)。`馬情報/予想で捨てる情報.md` の調教の扱いに従う
6. 動画IDを `調教動画済み.txt` に足す。見終わった 映像/調教_<ID>/ は `馬情報/削除したもの/` に移す(動画は大きいので video.* を消さずに移す)

## 2. 過去の分の書き起こし(検証用のデータを作る)
- 1が無い回は、`bash 自動実行/YouTube/jra_chokyo.sh next 古い` で古い方から1回2本まで、1の3・6と同じように書き起こす(2025〜2026年の約130本)
- 結果を見ながら書かない(タイムと併せの位置は見たまま。印象は書かない)

## 3. 検証(書き起こしが60レース以上たまったら)
- 結果は `馬情報/過去レースデータ/全期間/<年>/レース.jsonl`(name がレース名、date が日付)から、馬名で着順・単勝オッズを引く
- 単勝オッズのHarville式の3着以内率に対して、実際の3着以内率がどうずれるかを、次で分けて見る: 1Fの速さ(コース別に順位)、全体時計、併せの先着/遅れ、単走/併せ、坂路/ウッド、追い切り日(水/木)
- 前半・後半(日付で半分)とも同じ向きに1から離れる条件だけを採用候補にして、`馬情報/的中率を上げるための検証.md` に「14. 調教タイム」として書く

## 4. ライブ配信のパドック(2026-10-31・11-01 に試す)
- JRA公式は土日に「中央競馬全レース中継」をライブ配信する。パドックが映るかを確かめるため、タスクスケジューラ「競馬_ライブ録画_20261031_1450」「…_20261101_1450」が14:50から45分録る(`live_rec.sh`。メインレースのパドックの時間帯)
- 録れたら(自動実行/YouTube/映像/ライブ_<名前>/sheet_*.jpg)、Read して `馬情報/パドック/ライブ配信の確認.md` に書く: パドックが映ったか、何頭がどれくらいの時間映るか、馬番・馬名が読めるか、画質で毛づや・発汗・歩様が分かるか
- パドックが映っていれば、そのレースの結果を見る前に、馬ごとに A良い/B普通/C悪い と見たことを `馬情報/パドック/判断の記録.csv` に書く(判断時刻の列に「録画を後で判断」)
- 使えそうなら、毎週の重賞の発走30分前から録って、発走前に判断する仕組みを作る案をユーザーに出す
